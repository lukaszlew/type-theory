## Part A — errors

### A1. The note on C2 gives it the wrong logical status

**Quote.** "C2 (consistency) is missing from the last item, because the smallest test-defined set, the terms that pass every test, is not Min: it contains λx.y. C2 holds for this collection if and only if that set has no closed member, that is, if and only if for every closed term t some list of strongly normalizing terms v⃗ makes t v⃗ leave SN. That was not settled for this page."

Also, in "Status of the claims", under *Open on this page*: "Whether the smallest test-defined set of §42 has a closed member, which decides whether C2 holds for that collection".

**Reason.** C2 is the statement "no closed term t has ⊢ t : ∀X.X". It is about derivations, and it does not mention any collection of sets; §13 has already proved it, through the collection of all type sets. So C2 holds, full stop, and nothing about TT can make it fail. What depends on the collection is whether the *proof* of C2 in §13 goes through when ∀ ranges over TT: that proof says "such a term would be in the set that ∀X.X names, which has no closed member", and with TT the set that ∀X.X names is the smallest member of TT. A reader who takes the sentence at face value is told that a theorem of §13 might be false for a different choice of semantics, which is not what is meant. (Rule 11: logical status explicit; §41 uses the same shorthand "both corollaries hold", but there it is harmless because the proof does go through.)

**Fix.** Replace the two sentences by: "C2 (consistency) is a statement about derivations and was proved in §13. What the last item leaves out is the proof of C2 through this collection: that proof needs the set that ∀X.X names, which is here the smallest test-defined set, to have no closed member. That set is not Min: it contains λx.y." — and then, by A2, "It has no closed member, by the lemma 'Every closed term fails some test', so the proof goes through and C2 is in the item after all." Update the *Open on this page* entry in the same way (it is no longer open, see A2).

### A2. The question marked "not settled" has a short proof: the smallest test-defined set has no closed member

**Quote.** "That was not settled for this page. A program checked, for every closed normal form of size at most nine, that one of a fixed battery of small tests fails it; this is evidence and not a proof."

**Reason.** It is a theorem, with a proof of the kind §2 and §5 already use. Statement and proof, in the page's style:

> **LEMMA · EVERY CLOSED TERM FAILS SOME TEST.** For every closed term t there is a test v1,…,vn with t v1…vn ∉ SN. So the smallest test-defined set, the set of terms that pass every test, has no closed member.
>
> **PROOF.** If t ∉ SN, the empty test fails it. Let t ∈ SN. Some run from t ends in a normal form t̂: every run is finite, so extend any run until no step is left. t̂ is closed, because a step never adds a free variable. A closed normal form is an abstraction: by §2 it has one of three forms, a variable applied to arguments has a free variable, and an abstraction applied to arguments has a step. So t̂ = λx1.…λxk.s with k ≥ 1 and s not an abstraction. s is a normal form, as a subterm of one, and it is not an abstraction, so it is a variable applied to arguments, s = xi u1…um, where the variable is one of x1,…,xk because t̂ is closed. Take the test v1,…,vk,vk+1 with vj = I for j ≠ i and j ≤ k, vi = λz1.…λzm.δ, and vk+1 = δ. Each of these is a normal form, so it is in SN. Then
>
> t̂ v1…vk vk+1 →h … →h vi u1′…um′ δ, by k head steps, where uj′ = uj[v1/x1,…,vk/xk],
>
> and vi u1′…um′ δ = (λz1.…λzm.δ) u1′…um′ δ →h … →h δ δ = Ω, by m head steps, because δ is closed and the substitutions for z1,…,zm change nothing. So t̂ v1…vk+1 reaches Ω by steps, and it is not in SN by R1 (subterms). The steps from t to t̂ are steps of t v1…vk+1 as well, so t v1…vk+1 reaches t̂ v1…vk+1, and t v1…vk+1 ∉ SN, by R1 (subterms) again. ∎

The case m = 0 reads vi = δ and vi δ = δ δ. The case where xi occurs again inside the uj needs nothing: the uj′ need not be in SN, because the run to Ω never looks inside them. The program `tests/review5_check.py` runs exactly this test on every closed normal form of size ≤ 10 and finds Ω after k + m head steps in every case.

**Consequences and fix.**
1. Add the lemma (status "here, unreviewed" until a second reader has it) after the example "Three test-defined sets", or as a fifth item of the main lemma.
2. The item *theorem* can then say "the soundness theorem and both corollaries hold", with the proof: "C2: ∀X.X names the intersection of all members of TT, which by the item *arrow and intersection* is the orthogonal of the set of all tests, and that set has no closed member by the lemma 'Every closed term fails some test'."
3. Remove "That was not settled for this page" and the sentence about the program, or keep the program as a one-line remark that it agrees with the lemma. Remove the entry from *Open on this page* (the union question stays). The sentence in the status list "the computer check it mentions ran over …" goes with it.
4. The remark of §13 lists as its fifth requirement "that Min is a member, so that ∀X.X names Min". With TT this is false and C2 still goes through, so the requirement that C2 actually uses is weaker: "that the smallest member of the collection has no closed member". Research rule 10 (prefer the least committed object) says to state that one; Min satisfies it for SAT, HC and CR, and the lemma above gives it for TT. This also makes the sentence "C2 (consistency) was the one item that asked for Min" in the proof of *theorem* unnecessary.

### A3. The argument that λx.y passes every test has a gap at n = 0 and skips the step to SN

**Quote.** "The term λx.y passes every test, because (λx.y) v1…vn reaches y v2…vn, a member of Base, and λx.y is an abstraction, so it is not in Min."

**Reason.** The claim is true, and it carries the item *strictly* and the identification of the smallest test-defined set. But as written: (i) for the empty test (n = 0) there is no v1 and nothing is reached; the term is λx.y itself, which is in SN because it is a normal form; (ii) for n ≥ 1, "reaches a member of Base" does not by itself give "is in SN": one needs that the head step is safe (its argument v1 is in SN because a test consists of strongly normalizing terms), that y v2…vn ∈ SN by R2 (variable applied), and then R3 (safe head step). (iii) "an abstraction, so it is not in Min" uses that Min contains no abstraction, which is proved only inside the proof of "Head-closed type sets are sets of values" in §41 ("Min contains no abstraction, because every member reaches a member of Base by head steps and an abstraction has none"); say it or cite M2. (Rule 12: no skipped step.)

**Fix.** "λx.y passes every test. The empty test: λx.y is a normal form, so it is in SN. A test v1,…,vn with n ≥ 1: (λx.y) v1 v2…vn →h y v2…vn is a head step, safe because v1 ∈ SN, and y v2…vn is in Base, so in SN by R2 (variable applied); so (λx.y) v1…vn ∈ SN by R3 (safe head step). And λx.y is not in Min, because every member of Min reaches a member of Base by head steps, by M2 (generated), and an abstraction has no head step and is not in Base." See B5 for where this should live.

## Part B — imprecisions and rule issues

**B1. Rule 1 (one word, one meaning): "test" now has a technical meaning and an older informal one.** §42 defines "a test" as a list of strongly normalizing terms. The page already uses the word informally: §5 "DEFINITION · TWO TEST TYPE SETS" and "Later examples use these two to test which terms belong to other sets"; §6, §15 and §45 "test argument"; §8 "the membership test in M2"; §5 proof of M2 "For the test:"; the opening "§28, §29 and §30 test the three constructions"; §24 "test other families against it"; §27 "tested against the type set". After §42, "test type sets" reads as "type sets defined by tests", which TI and TK are not (TI is the example of a set that is *not* test-defined). Fix: rename TI, TK to "two hand-built type sets" and "test argument" to "a variable as argument", or choose another word in §42 ("argument list" is what the section itself says it means). The cheap fix is in §5, §6, §15, §45, since "test" is the literature's word for §42.

**B2. Rule 7 (no definition inside a lemma).** "Write TT for the collection of test-defined sets." is the first sentence of the lemma's statement. §41 puts "Write SAT for …, HC for …, CR for …" in a paragraph of its own before the lemma. Do the same.

**B3. Rule 3 (names, not pointers).** "the lemma in §40" (name: "Candidates are the type sets that are closed under steps"); "the lemma on values in §41" (name: "Head-closed type sets are sets of values"); "as the first item of the lemma shows" and "missing from the last item" (names: the items *candidates* and *theorem*); "SN was the first example" (name the example or just say "SN is the orthogonal of the set containing only the empty test").

**B4. Rule 8 (notation defined once before use).** v⃗ and w⃗ for a list v1,…,vn, and t v⃗ for t v1…vn, are used in the note, in the proof and in §41's commuting-lemma proof (line "t′ = (λx.u′) v v⃗") without ever being introduced. One sentence in the definition of a test fixes it: "A test is written v⃗ for short, and t v⃗ is t v1…vn."

**B5. Rule 16 (a proof never depends on an example frame).** The proof of *strictly* rests on "λx.y, which passes every test", and that fact is established only in the example "Three test-defined sets". The note after the lemma ("the terms that pass every test … contains λx.y") and the identification of the smallest test-defined set rest on it too. Either put the sentence from A3 into the proof of *strictly*, or state a one-line lemma "λx.y passes every test, and so belongs to every test-defined set" before the examples, and let the example cite it.

**B6. Rule 11 (status of every claim).** The sentence "sets of the form P⊥ [are called] biorthogonals, because P⊥ is also the orthogonal of the set of all tests that every member of P⊥ passes" states a mathematical fact (P⊥ equals the orthogonal of its own orthogonal) with no proof and no status, inside a definition frame. The fact is right; the proof is two lines: write Q for the set of tests that every member of P⊥ passes; P ⊆ Q, so Q's orthogonal is inside P⊥; and every member of P⊥ passes every test in Q by the definition of Q, so P⊥ is inside Q's orthogonal. Either give it or mark it ("worked out here, one line"). "In the literature … is called" is a general-knowledge claim; that status is said for §44's table in the status list but not for this sentence.

**B7. Rule 6 and research rule 1 (justify each clause of a definition).** The definition says a test is a list of *strongly normalizing* terms and does not say why. The reason is one sentence: if a test contained a term outside SN, no term would pass it, by R1 (subterms), so P⊥ would be empty and not a type set; and the Base condition in the item *candidates* uses exactly that the terms of a test are in SN. The exclusion of the empty P is explained; this one should be too.

**B8. Rule 19 and the "Uses" lines.** (a) §42's header says "No later section uses it", but §44's table row says "the conditions then follow, as §42 proves for tests that are argument lists": §44 rests on §42's item *candidates* for that claim, and §44's Uses line (§14, §40) does not list §42. Either add §42 to §44's Uses line and change §42's header to "Used by §44", or reword §44's row as a passing mention. (b) §42's opening sentence and its remark refer forward to §44 ("The table of §44 lists …", "That is the sense in which §44 said …"). Forward references are passing mentions and the rule allows them, but the motivation of a section should not depend on a table the reader has not yet seen; one clause saying what the table says would make §42 self-contained. (c) Reachability: §42 lists only §41; through §41 → §7, §40 → §13 → §9, §12 → §8, §10 → §5 → §2, §4 → §1, every result §42 cites is reachable (the §13 remark, the §40 lemma, R1–R3 of §2, M2 of §5, the union lemma of §8). This follows the convention §41 already uses (it cites §13 and §8 in proofs while listing only §7 and §40), so it is consistent; but rule 19 as written ("every earlier section a text refers to is among the sections it uses") would ask §42 to list §13 and §40, which it cites by number. Decide which reading the rule has and say so once at the top of the page.

**B9. Rule 2 and rule 13 (a term explained before use).** The opening paragraph uses "continuation" ("where a test is a continuation"); the plain explanation ("a whole context waiting for the term") arrives only in the closing remark. Move the explanation to the first use or drop the word from the opening.

**B10. The remark overclaims what "follows" in the continuation setting.** "The conditions of a type set are never stated in that setting, because they follow, as the first item of the lemma shows." The first item shows that, for tests that are argument lists, all three conditions follow. For Krivine's realizability (general knowledge, as the remark says): the analogue of the closure condition follows from the pole being closed under anti-evaluation; the Base condition has no analogue, because the terms there are closed; and the SN condition is a property of the pole, not something that follows. The next sentence already says the right thing ("what the lemma proves of P⊥ is the closure condition"). Fix: "because the closure condition follows". Also "a set of tests closed under the right operations then defines …": in Krivine's setting any set of stacks is a falsity value; the closure is required of the pole, not of the set of tests. Say "a set of tests, with a fixed notion of passing that is closed under the right operations" or drop "closed under the right operations". As an account marked "general knowledge, not checked", the remark is otherwise fair: tests as stacks (continuations), the arrow computed from tests u·w⃗ with u in the premise and w⃗ a test of the conclusion, and ∀ as the orthogonal of a union of test sets are how Krivine's realizability is set up; for Parigot's λμ the framing is that of the later orthogonality-based strong-normalization proofs rather than Parigot's own, which the hedge covers.

**B11. Rule 4 (parts of a lemma get meaningful names).** The item *arrow and intersection* ends with "SN is test-defined", which is there to give "the collection is not empty" for the item *theorem*. It is a third claim under a name that does not announce it. Give it its own item ("not empty") or fold it into *theorem*'s proof by citing the example.

**B12. Rule 1 (word choice).** "makes t v⃗ leave SN": on this page "leave" is used for "a member can leave a type set by running" (§5, §23). A term does not leave SN; say "puts t v⃗ outside SN" or "t v⃗ ∉ SN". "stand up to every one of them" in the remark is informal; "pass every one of them" is the page's word.

**B13. Rule 12 (no skipped step) in *strictly*.** "TI is a candidate by the item candidates of the lemma on values in §41": that item says a head-closed type set is a candidate iff its set of values is closed under steps. That TI is head-closed with set of values {I} is the item *operations* ("For a value v, Gen({v}) is head-closed and its set of values is {v}"), and that {I} is closed under steps is that I has no step. Cite both items, or cite the example "Three type sets, one from each collection" of §41, which already does this.

**B14. Rule 12 in *arrow and intersection*.** (a) "the set P′ of tests u, w⃗ with u ∈ T and w⃗ ∈ Q": for u, w⃗ to be a test, u has to be in SN, which is the SN condition of T from the item *candidates*; say so. (b) "which is nonempty because T contains the variable x": also needs Q nonempty, which it is by assumption; say "and Q is not empty". (c) "the orthogonal of the union of the Pi, which is nonempty": because the index set is nonempty and each Pi is.

**B15. Status list.** (a) The paragraph "From general knowledge, and not checked against sources" lists §44's table and §41's sentence on values, but not §42's remark on λμ and Krivine, which carries the same status inline. Add it. (b) "closed normal forms of size at most nine" and "size at most five": "size" of a term is not defined anywhere on the page; after A2 the sentence can go, otherwise say "number of symbols". (c) After A2, the *Open on this page* entry and the §42 part of "Worked out for this page, and not reviewed" need updating; the new lemma joins the unreviewed list until read.

**B16. Rule 7 (one definition per line).** "For a nonempty set P of tests, P⊥ is the set of terms that pass every test in P. A set of terms is test-defined if it is P⊥ for some nonempty P." Two definitions on one line; split them.

**B17. Rule 11 for the opening paragraph.** "this is the form of semantics used for classical logic and for languages with effects" is general knowledge; the status marker appears only in the remark at the end. Add "from general knowledge" at the first occurrence, or move the sentence to the remark.

**B18. Research rule 11 (name the price) and rule 10, on the union.** "it loses the union lemma, or at least the one-line proof of it" is honest about what was not checked, and the earlier sentence says it was not checked. One structural observation that costs nothing and helps a reader place TT: the intersection of all members of TT is the orthogonal of the set of all tests, so by the item *arrow and intersection* the smallest member exists and is test-defined, and by A2 it is a type set strictly between Min and every other member with no closed member. Whether TT is closed under union was not settled by this review either; the natural attempts (unions of sets of the form {(a)}⊥) collapse to cases where one set contains the other, so a counterexample, if there is one, needs tests that the two sets cannot both absorb.

## Checks asked for, with answers

1. **P⊥ for nonempty P is a type set closed under steps; the appeal to §40's lemma.** Yes. SN condition from any one test and R1; Base condition because a member of Base applied to strongly normalizing terms is in Base (this is where "tests are lists of strongly normalizing terms" is used); closure condition because a head step survives any number of trailing arguments with the same argument, and R3; CR2 because t v⃗ → t′ v⃗ and R1. The §40 lemma says exactly that a type set with CR2 is a candidate.
2. **TI = Gen({I}) is a candidate and not test-defined; λx.y.** Yes on both. λx.y is in every P⊥: the empty test is passed because λx.y is a normal form; a test with n ≥ 1 is passed by one safe head step to y v2…vn ∈ Base ⊆ SN and R3. Tests whose terms contain y free change nothing: y v2…vn is in Base whatever the vi are, and substitution for x never touches the free y. λx.y ∉ TI by M2, since λx.y has no head step, is not I and is not in Base. The written argument has the n = 0 gap (A3).
3. **T ⇒ U test-defined with the set P′ of tests u, w⃗; nonemptiness; intersections.** Yes. P′ is a set of tests because u ∈ T ⊆ SN; P′ ≠ ∅ because x ∈ T and Q ≠ ∅. The intersection of P_i⊥ over a nonempty index set is (⋃ P_i)⊥, and ⋃ P_i ≠ ∅.
4. **The *theorem* item follows from the §13 remark; the C2 claim.** The item follows: the four things the remark lists apart from Min are the items *candidates*, *arrow and intersection*, and "SN is test-defined". The claim "C2 holds for this collection iff the smallest test-defined set has no closed member" is right only under the convention that "holds for this collection" means "is proved through this collection" (A1); under that convention "if" is the §13 proof and "only if" says that the semantic argument has nothing else to exclude a closed member. The smallest test-defined set is the set of terms passing every test: yes, it is the intersection of the nonempty collection TT, which the item *arrow and intersection* computes as the orthogonal of the union of all nonempty P, that is, of all tests. And it has no closed member (A2), so C2's proof goes through.
5. **The three examples.** SN: right. {t : t I ∈ SN}: K I → λy.I, a normal form; (λx.x x x) I → I I I → I I → I, one redex at each stage; (λx.x δ δ) I → I δ δ → δ δ, so outside SN by R1. All right. Min not test-defined: right, with the gap of A3.
6. **The definition.** "Nonempty P" is the right restriction and the reason is given. "Strongly normalizing" in the definition of a test is also needed and its reason is not given (B7). The orthogonal/biorthogonal note is mathematically right (B6 for its status).
7. **The remark.** Fair as a hedged general-knowledge account, with the two overclaims in B10. "The closure condition follows" is accurate for the lemma's setting.
8. **Status and order.** Every claim in the lemma carries a status; the lemma is "here, unreviewed", matching the status list. Terms used before definition: "continuation" (B9), v⃗ (B4). Uses line: everything §42 relies on is reachable from §41 (B8c).
