### A1. The lemma refutes a fact about sets for an F chosen by hand; the page concludes that the rule fails. A type expression is needed, and three lines supply it (if the system has ∧).

Quoted, line 2997: "It cannot take its place with the rule that uses a member unchanged: the lemma after this example says what part of that rule stays true and what part fails." Line 3011: "This answers the question that the example left, and the answer is no." Line 3951: "the smallest such set above a union cannot serve existential types with the rule that uses a member unchanged, by a lemma there that is not reviewed".

Why it is a gap. The lemma shows: there are test-defined B1, B2 with v v ∈ SN on B1 ∪ B2 and a t in (B1 ∪ B2)° with t t ∉ SN. To be about existential types this needs a function F from TT to TT with ⋃C F(C) = B1 ∪ B2. One exists (B1 at SN, B2 at every other member, the device the example uses for Ta and Tb), but no type expression is shown to name such a function. By section 13 a rule is false only if true judgments above the line give a false judgment below, and a judgment is about type expressions. Section 18 says a membership fact "is what makes the rule true"; the failure of the fact for some function F does not make the rule false. So what is proved is: the membership fact of section 22 fails over TT, for a function that no type expression is known to name.

The gap closes in three lines if ∧ of section 19 is in the system (derived here by hand, not read by anyone else). Let F(C) = C ∩ (C ⇒ SN). It is what X ∧ (X → Y), the example type expression of section 19, names if Y is sent to SN.

- For every C in TT and every v ∈ F(C): v ∈ C and v ∈ C ⇒ SN, so v v ∈ SN, by apply.
- The proof of the lemma shows Bi ⊆ Ti. So F(Ti) = Ti ∩ (Ti ⇒ SN) = Ti ∩ Bi = Bi, and B1 ∪ B2 ⊆ ⋃C F(C).
- A test that every member of the larger set passes is passed by every member of the smaller. So (B1 ∪ B2)° ⊆ (⋃C F(C))°, and t is in (⋃C F(C))°. And t t ∉ SN.

As judgments, with ∃X.A naming (⋃C ⟦A⟧ρ[X↦C])°: w : ∃X.(X ∧ (X → Y)) ⊨ w : ∃X.(X ∧ (X → Y)) is true; w : ∃X.(X ∧ (X → Y)), x : X ∧ (X → Y) ⊨ x x : Y is true, and X is free neither in the context nor in Y; the conclusion w : ∃X.(X ∧ (X → Y)) ⊨ w w : Y is false: send Y to SN and replace w by t.

For System F with ∃ and without ∧ I found no type expression that does it: the obvious candidates name functions that are monotone or antitone in C, and for those the union is the value at one end, which is test-defined (for example ⋃C (C ⇒ D) = (smallest member) ⇒ D, and ∀Z.Z → X gives ⋃C (SN ⇒ C) = SN ⇒ SN).

### A2. "the line is ... whether it is used at the head" and "this is all there is" are false as stated.

Quoted, line 3011: "So the line is not how often the member is used, but whether it is used at the head." and "The second item shows that this is all there is."

Why. The three items show: the fact holds for s = x u1...uk with x not free in the ui; it fails for s = x x; it fails for s = δ x. They do not draw a line, and the line named is not the line (all three points derived here by hand):

1. In s = x x the member is used at the head, and the fact fails. So "used at the head" is not sufficient; "used at the head and nowhere else" is what the first item has.
2. s = z (x u) (x u') with u, u' strongly normalizing and x not free in them: the member is used twice and never at the head of s, and the fact holds for every S and every test-defined U. Proof: let U = R⊥ and w ∈ R. If z (v u) (v u') w ∈ SN for every v ∈ S, then v u ∈ SN and v u' ∈ SN by R1 (subterms), so every member of S passes the one-term tests u and u'; so every t ∈ S° passes them; so z (t u) (t u') w is in Base, and in SN by R2. This is the pattern by which the lemma's own proof puts t = λm. z (m e1) (m e2) into (B1 ∪ B2)°. The same holds for s = λq. x u.
3. s = δ (x I): the member occurs once and is at the head of its own application, and the fact fails. Take S = { λq.b : b ∈ B1 ∪ B2 }. For v = λq.b: (λq.b) I is in Ti by the closure condition, because b ∈ Bi ⊆ Ti; so b ((λq.b) I) ∈ SN; so ((λq.b) I) ((λq.b) I) ∈ SN and δ ((λq.b) I) ∈ SN, by R3 twice. And λq.t ∈ S°: λq.t is a normal form, so it passes the empty test; and for n ≥ 1, if every (λq.b) v1...vn is in SN then every b v2...vn is, by R1, so v2,...,vn is a test that every member of B1 ∪ B2 passes, so t passes it, so (λq.t) v1...vn ∈ SN by R3. But δ ((λq.t) I) reaches δ t and then t t. (The script confirms the two runs for b = g1, g2 and for t.)

The exact statement is short. For a term s and a test-defined U, write W for the set of the strongly normalizing v with s[v/x] ∈ U. Then the fact "if s[v/x] ∈ U for every v ∈ S, then s[t/x] ∈ U for every t ∈ S°" holds for every nonempty S of strongly normalizing terms if and only if W is empty or test-defined. Proof: if W is test-defined and S ⊆ W, then S° ⊆ W, because S° is the smallest test-defined set that contains S; if W is not empty and the fact holds for S = W, then W° ⊆ W, so W = W° is test-defined. The item "at the head" says that W is test-defined for s = x u1...uk; the item "not with the term unchanged" says that { v ∈ SN : v v ∈ SN } is not.

Fix. Minimal: replace the two sentences by "So it is not how often the member is used that decides: one use as an argument is enough to fail. The items do not say for which other s the fact holds." Better (one more item or a remark, see C2): state the criterion with W.

### A3. With the new lemma on the page, "His remedy changes the rule and not the set" is false for the sets of this section.

Quoted, line 2997: "His remedy changes the rule and not the set: a member is used through a new form of term, let x = t in c, which takes its step only once t has become a value, and with it the rule is true for candidates and for biorthogonals."

Why. The lemma's t = λm. z (m e1) (m e2) is an abstraction. For β, Riba's values are the abstractions (R:289-291: "the values for β-reduction in evaluation contexts E[ ] ∈ E⇒ ::= [ ] | E[ ] t are the λ-abstractions λx.t"). So t has already "become a value", it is in (B1 ∪ B2)°, and let x = t in x x would step to t t ∉ SN, while let x = v in x x is in SN for every v ∈ B1 ∪ B2 (v ∈ SN; a reduct v' of v is in the same Bi, because test-defined sets are closed under steps; so v' v' ∈ SN). So with the set S° of this section, the new form of term and its rule would not make the rule true. Waiting for a value is not what does it.

What does it in Riba's paper is that the contexts let x = [ ] in c are added to the contexts that serve as tests: "The delicate operation is to extend the set of elimination contexts. We need to extend E both with contexts of the form (let x = E[ ] in c) and with contexts having the same shape as those in E" (R:379-381), and the elimination-based set is shown to be "the orthogonal of the non-empty subset of SN" made of the contexts E[(let x = [ ] in c)] (R:466-470). With more tests the smallest biorthogonal above the union is a smaller set; the lemma's t fails the test let x = [ ] in x x. Riba's own sentence is about the definition, not the set: the let "does not change the definition of the type interpretation using the closure of unions" (R:440-441). The note under the lemma has the right explanation for Pitts ("the use, followed by a test of the result, is one test of the member"); the sentence on Riba, two frames before, says the opposite.

(The claim about let over the tests of this section is derived here in outline and read by no one else; it needs Lemma R for the calculus with let, which is not on the page.)

Fix: "His remedy keeps the definition of the set, the smallest member of the collection above the union, and changes the terms: a member is used through a new form of term, let x = t in c, which takes its step only once t has become a value; the contexts let x = [ ] in c then count among the tests, so the collection is not the TT of this section and the smallest member above the union is a smaller set. With it the rule is true for candidates and for biorthogonals. With the tests of this section the new form would not be enough: the term t of the lemma "Using a member ..." is an abstraction, so it is a value already."

### A6. "evaluate to an answer" is not what the paper observes.

Quoted, line 3051: "a pair of terms passes a pair of tests if both programs evaluate to an answer or neither does".

Source. Definition 3.9 (P:676-689): (M, M') ∈ s⊤ if and only if for all (S, S') ∈ s (S ⊤ M ⇔ S' ⊤ M'), and S ⊤ M means S M ⇓ nil (Theorem 3.6, P:563-567). "here we take a program to be a closed term of list type and we observe whether or not it evaluates to nil" (P:265-266). Evaluation to a non-empty list is evaluation to a value and does not count: for a pair of cons cells "neither Id ⊤ L, nor Id ⊤ L' hold" (P:962-963). Read naturally, "an answer" is any value, and that gives a different relation (the pair of nil and a cons cell would pass the pair of empty stacks). The word "answer" is not in the paper and is not explained on the page.

Fix: "if both programs evaluate to the empty list or neither does; a program is a closed term whose type expression is a list type".
