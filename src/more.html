Three more additions follow, each at the price that the addition lemma of {{price}} states. Each is given by its set, by the lemma that the set is a type set, and by its membership facts. The form of type expression, the clause and the rules are then read off, as {{and}} did for ∧, and the addition lemma gives Lemma N, the soundness theorem and both corollaries for the system with the new rules.

Addition · Subtyping

Set
No new set. The relation T ⊆ T′ between type sets.
Lemma
Nothing to check.
Facts
If t ∈ T and T ⊆ T′ then t ∈ T′. Inclusions come from true facts: Min ⊆ T ⊆ SN; if T′ ⊆ T and U ⊆ U′ then T ⇒ U ⊆ T′ ⇒ U′; ⋂C F(C) ⊆ F(D); and the laws of ∩ in {{andlaws}}.

Example · Subtyping

ID ⊆ ID ⇒ ID, by the fact ⋂C F(C) ⊆ F(D), with D = ID. So the self-application example reads: pass to a larger type set, then apply.

Example · A bigger input gives a smaller arrow

A smaller input set gives a larger arrow, so SN ⇒ SN ⊆ TI ⇒ SN, because TI ⊆ SN. The inclusion is strict: δ is in TI ⇒ SN and not in SN ⇒ SN. With fewer inputs to handle, more terms qualify. In standard terms, the arrow is contravariant in its first argument.

Why δ ∈ TI ⇒ SN: take u ∈ TI. Its head steps lead to I or to a variable applied to arguments. I u ∈ SN because u ∈ SN, and a variable applied to strongly normalizing arguments is in SN by R2 (variable applied). R3 (safe head step) carries this back along the head steps, so u u ∈ SN, and then δ u ∈ SN.

Addition · Least fixed points

Set
For a function F from type sets to type sets, μF is the intersection of all type sets C with F(C) ⊆ C. F is monotone if the following holds: if C ⊆ C′ then F(C) ⊆ F(C′).
Lemma
μF is a type set for every F, as an intersection of a nonempty collection: SN is in the collection, since F(SN) ⊆ SN. If F is monotone, then F(μF) = μF. For every C in the collection F(μF) ⊆ F(C) ⊆ C, so F(μF) ⊆ μF. Then F(F(μF)) ⊆ F(μF), so F(μF) is in the collection and μF ⊆ F(μF). This is the Knaster–Tarski theorem.
Facts
For monotone F: t ∈ μF if and only if t ∈ F(μF), with the term unchanged. Induction, for every F, monotone or not: if F(C) ⊆ C for a type set C, then μF ⊆ C, because μF is the intersection of all such C. Extended induction, for monotone F: if F(μF ∩ C) ⊆ C for a type set C, then μF ⊆ C; for D = μF ∩ C is a type set with F(D) ⊆ F(μF) = μF, because F is monotone, and F(D) ⊆ C, so F(D) ⊆ D and induction gives μF ⊆ D. The name is Matthes’s; in his thesis induction is what motivates iteration over an inductive type, and extended induction is what motivates primitive recursion, where the step may use the member itself and not only the result for it. The rules carry the side condition that F is monotone, which the usual presentations state as “X occurs positively in A”; without it the two rules are false, because μF is still a type set but need not be a fixed point.
Greatest
The other end exists in the same way: νF is the union of all type sets C with C ⊆ F(C). It is a type set for every F, by the union lemma of {{ops}}: the collection is not empty, because Min is inside F(Min). Every type set C with C ⊆ F(C) is inside νF, for every F, by the definition. If F is monotone, then F(νF) = νF, by the argument for μF with the inclusions turned round. This is the Knaster–Tarski theorem again, a textbook argument, read for type sets here and re-derived by the reader of the seventh review; the rules for a type expression that names it are not written out on this page.

Example · Least fixed points

Numbers that carry their predecessor. Let F(C) = ⋂D (D ⇒ ((C ⇒ D) ⇒ D)). It is monotone, because C sits to the left of two arrows. Zero is λz.λs.z, which is in F(C) for every C. If n ∈ μF then its successor λz.λs.s n is in F(μF) = μF.

Addition · Existential types

Set
⋃C F(C), the terms that are in F(C) for at least one type set C.
Lemma
It is a type set. It is the union of a nonempty collection of type sets, so the union lemma of {{ops}} applies.
Facts
If t ∈ F(D) then t ∈ ⋃C F(C). To use a member t: if s[v/x] ∈ U for every type set C and every v ∈ F(C), then s[t/x] ∈ U.
Encoding
The existential type can also be had with no new set and no union. Let E = ⋂D ((⋂C (F(C) ⇒ D)) ⇒ D), which is built from ⋂ and ⇒ alone. Then λx.λk. k x is in ⋃C F(C) ⇒ E, and λe. e I is in E ⇒ ⋃C F(C), and the second, applied to the first applied to t, reaches t by four head steps. For the first: if t ∈ F(C0) and k ∈ ⋂C (F(C) ⇒ D), then k t ∈ D by instantiate and apply, and (λx.λk. k x) t k reaches k t by two safe head steps. For the second: instantiate e at D = ⋃C F(C), which is a type set by the union lemma; I is in F(C) ⇒ ⋃C F(C) for every C, by the closure condition; so e I is in the union. With E a member is not used with the term unchanged: it is applied, e k. The encoding is the usual one. That it and the union have terms both ways is a statement of Riba’s, for candidates and for biorthogonals, with terms that use a let of his; the two terms here and the proof for type sets were worked out here and re-derived by the reader of the seventh review. E is the form to take where a collection is not closed under union, as in {{tests}}.
Caution
Only the length of the proof depends on the conditions chosen in {{typeset}}. For type sets, closure under union is the union lemma, which takes one line. For Girard’s reducibility candidates, which {{cmpsets}} compares, the union of candidates is also a candidate, by a proof given there, together with the history of the question. For the sets defined by tests, in {{tests}}, the union of two of them need not be one, by a lemma given there, and existential types in this form are not available.

Example · Existential types

δ ∈ ⋃C (C ⇒ C), with C = ID, although δ ∉ ⋂C (C ⇒ C). The term sends some type set into itself, and not every type set.
