A judgment Γ ⊢ t : A is a statement under hypotheses, the entries of Γ. On this page a hypothesis is read in one way throughout, and that reading decided several things that looked unrelated: why variables are in every type set, why consistency speaks of closed terms, why Cedille’s rules ρ and φ fail, and what a false hypothesis does. This section states the reading once and lists what follows from it.

Definition · The reading of a hypothesis

By the definition of a true judgment in {{judg}} and {{dep}}, the hypothesis x : B means: x stands for an arbitrary member of the type set that B names. A judgment under Γ is true if it holds for every choice of members, one for each hypothesis.

Two consequences are immediate. A hypothesis never has no instance, because every type set contains the variable x itself, by the Base condition; so a judgment is never true for lack of instances. And a variable is a term that does nothing, as the remark on contexts in {{rules}} says, so the instance “x itself” is always available, which is what C1 (strong normalization) uses.

Lemma · What a false hypothesis doeshere, reviewed

Let the type expression B name Min under every assignment, as ∀X.X does, or {K ≃ I} in {{equality}}. Then, for every Γ, t and A:

weakening
If Γ ⊨ t : A, then Γ, e : B ⊨ t : A, for a variable e not free in t, Γ or A. This holds for every B, and does not use that B names Min.
from it
Γ, e : B ⊨ e : A, for every A: a proof of a false statement proves everything.
not all
e : B ⊨ Ω : A is false, and so is e : B ⊨ t : A for every closed term t and every A that names Min, such as e : ∀X.X ⊨ I : ∀X.X.

So a false hypothesis gives “anything from it” but not “anything at all”: a judgment under a false hypothesis still says something about its term. The instances of e are the members of Min, terms that get stuck at a variable, and the term t has to be in ⟦A⟧ when e is any of them.

Proof

Weakening. Adding a hypothesis that t, Γ and A do not mention changes neither t[ρ] nor the sets, by N0 (free variables).

From it. Every instance of e is in Min, and Min is inside ⟦A⟧ρ by M3 (smallest).

Not all. Ω[ρ] = Ω ∉ SN, so it is in no type set. A closed t has t[ρ] = t, and Min has no closed member, by M3 (smallest). ∎

Here is what the reading decided, in the order the page met it.

  • The Base condition of {{typeset}} is the reading applied to C1 (strong normalization): the judgment x : A ⊢ x : A has to hold of the instance “x itself”, so x has to be in every set that A can name; and then so has x u, because the arrow checks its members on x. Narrow point 2 in {{simpler}} showed that nothing less works.
  • Consistency in {{rules}} is stated for closed terms because an open term under a hypothesis is never excluded: e : ∀X.X ⊢ e : ∀X.X is derivable and true. What cannot be derived is a closed proof of ∀X.X.
  • Limit 1 of {{limits}}: a rule that draws a conclusion from the mere existence of a member of some type set is false, unless the conclusion holds of every member of that type set, because every type set has members, the variables. The rules ρ and φ of {{equality}} are two such rules: each concludes something about a term from a hypothesis e : {t ≃ t′}, and the hypothesis has instances even when the equation is false. The rule δ is true because it draws its conclusion from Min itself.
  • Stump’s semantics for Cedille, in the remark of {{equality}}, takes the other reading: a type names a set of closed terms, so a false hypothesis has no instance, every judgment under it is true for lack of instances, and ρ and φ hold. The price of that reading is that the theorem is consistency alone, not strong normalization, and the remark lists what else it changes.
  • Casts in {{induct}}: an inclusion between type sets cannot be a hypothesis, for the same reason, and became a condition on an index set instead.

Remark · What the reading does not give

Under this reading a hypothesis is a term, never a fact about terms. “x is a natural number” can be a hypothesis, by giving x a type expression for the naturals; “u and v are equal” can be one only as a type set, EQ(u, v) or E(u, v), whose members are proofs, and the lemma on ER in {{equalities}} says which equalities can be added that way. A hypothesis whose content is used by retyping a term, as ρ, φ and casts do, is what the reading cannot give.
