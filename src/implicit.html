Cedille is the system that Stump built after System S; its theory is the Calculus of Dependent Lambda Eliminations. It replaces self types by three constructions: the dependent intersection of {{dinter}}, the implicit product of this section, and an equality between terms, in {{equality}}. The implicit product is due to Miquel. As a set, it is the intersection over the members of a type set.

Definition · Intersection over the members of a type set

For a type set T and a function V from terms to type sets, the intersection over the members of T, written ⋂u∈T V(u), is the intersection indexed by T in the sense of {{ops}}: the terms that are in V(u) for every u ∈ T.

T contains Base, so it is not empty, and the intersection is a type set by the intersection lemma of {{ops}}; generalize and instantiate of {{facts}} hold for it. Nothing is asked of V along steps. Contrast with the dependent arrow of {{darrow}}. A member t of Πu∈T V(u) is given u as an argument: t u ∈ V(u). A member t of ⋂u∈T V(u) is in V(u) without being given u.

Definition · The implicit product

There is one more form of type expression: ∀x:A.B, where the term variable x may be free in B. Cedille calls it an implicit product.

One clause is added:

⟦∀x:A.B⟧ρ = ⋂u∈⟦A⟧ρ ⟦B⟧ρ[x↦u]

Two rules are added:

RuleFromConclude
∀ in, for termsΓ, x:A ⊢ t : B, with x not free in tΓ ⊢ t : ∀x:A.B
∀ out, for termsΓ ⊢ t : ∀x:A.B and Γ ⊢ u : AΓ ⊢ t : B[u/x]

The term is the same above and below each rule, as it is for ∧ in {{and}}. Contrast with “Π in” in {{dep}}: from Γ, x:A ⊢ t : B it concludes Γ ⊢ λx.t : Πx:A.B. The implicit rule drops the λ, and in return asks that t does not use x. In Cedille the term carries an abstraction Λx.t and an application t -u for these two rules; erasure removes both, and the rules above are what is left.

Lemma · The two rules for the implicit product are truehere, reviewed

The rules “∀ in, for terms” and “∀ out, for terms” are true. So, by the addition lemma of {{price}} as extended in {{dep}}, Lemma N, the soundness theorem and both corollaries hold with them added.

Proof

The addition lemma. The clause computes the set from the type set that A names and the family w ↦ ⟦B⟧ρ[x↦w], by the intersection over the members of the first, which is a type set by the definition’s note and has no term input.

∀ in, for terms. Fix ρ with ρ(xi) ∈ ⟦Ai⟧ρ for each variable of Γ. Take any u ∈ ⟦A⟧ρ and let ρ′ = ρ[x↦u]. The variables of Γ are still well placed under ρ′, because x is not free in their type expressions, by N0 (free variables). So the premise gives t[ρ′] ∈ ⟦B⟧ρ′. And t[ρ′] = t[ρ], because x is not free in t. So t[ρ] ∈ ⟦B⟧ρ[x↦u] for every u ∈ ⟦A⟧ρ, which is the clause.

∀ out, for terms. t[ρ] is in ⟦B⟧ρ[x↦u[ρ]] by instantiate, and that set is ⟦B[u/x]⟧ρ by N2 (substitution). ∎

Example · A term that works for every u without being told u

I ∈ ⋂u∈T (V(u) ⇒ V(u)) for every type set T and every family V, because I ∈ V(u) ⇒ V(u) for each u. So ⊢ I : ∀x:A. P x → P x is derivable, by the variable rule, “→ in” and “∀ in, for terms”. With the dependent arrow in the place of the implicit product, the term would have to be λx.I.

Example · Cedille’s natural numbers: induction with no recursive definition

Write cNat for the type set that ∀X.(X→X)→X→X names, with 0 = λs.λz.z and S = λn.λs.λz.s (n s z) as in {{self}}. For a family P, let

StepP = ⋂y∈cNat (P(y) ⇒ P(S y))

which is an intersection over the members of cNat. Let V(w) = ⋂P ( StepP ⇒ (P(0) ⇒ P(w)) ), with P over all families, and let

Nat′ = { t : t ∈ cNat and t ∈ V(t) }

which is the dependent intersection of {{dinter}} with cNat as its first part. Then Nat′ is a type set, 0 ∈ Nat′, S ∈ Nat′ ⇒ Nat′, and every t ∈ Nat′ satisfies t s z ∈ P(t) for every family P, every s ∈ StepP and every z ∈ P(0). That is induction, and the type set of the result mentions t.

Contrast with the Nat of {{self}}. There StepP was an intersection over the members of Nat itself, so Nat was defined in terms of itself and needed the least fixed point of {{more}}. Here y ranges over cNat, which was fixed first, and no fixed point is needed. This is Stump’s construction, with the argument order of this page.

The implicit product is what makes it work. If StepP were the dependent arrow Πy∈cNat (P(y) ⇒ P(S y)), then a member s would take y as an argument, and S t s z, which runs to s (t s z), would hand s one argument where it expects two. Stump makes the same point about erasure: the step function must erase to the step of the Church numeral.

Proof

Type set. Each V(w) is a type set, by the arrow lemma and the intersection lemma of {{ops}}. V is constant along steps, because each P is. So V is a family, and the lemma of {{dinter}} applies.

0 ∈ Nat′. For 0 ∈ V(0), take any family P, s ∈ StepP and z ∈ P(0). Then 0 s z →h (λz.z) z →h z, and z ∈ P(0). Both head steps are safe, because s and z are in SN. So 0 s z ∈ P(0) by the closure condition, twice. The same two steps, with any type set C in the place of P(0) and any s ∈ C ⇒ C, give 0 ∈ cNat.

S ∈ Nat′ ⇒ Nat′. Take t ∈ Nat′. For any type set C, s ∈ C ⇒ C and z ∈ C, the term S t s z reaches s (t s z) by three safe head steps, and t s z ∈ C because t ∈ cNat; so S t ∈ cNat. For S t ∈ V(S t), take any P, s ∈ StepP and z ∈ P(0). Again S t s z reaches s (t s z) by three safe head steps. Now t ∈ V(t) gives t s z ∈ P(t). And t ∈ cNat, so instantiate gives s ∈ P(t) ⇒ P(S t). So s (t s z) ∈ P(S t), and S t s z ∈ P(S t) by the closure condition.

Induction is t ∈ V(t), read off. ∎
