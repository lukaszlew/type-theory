The soundness theorem says that every derivable judgment is true. {{true}} showed that the converse fails, and every example so far could be repaired. The lemma “True and not derivable” is repaired by giving its variable a place in the context; its sharper case by ∧, with which every strongly normalizing term is typable ({{andsn}}); the law of {{andlaws}} by adding inclusions as rules. This section asks what is left after such repairs. For another semantics of sets the literature has a system of rules that derives exactly the true judgments, and it is quoted first. For the type sets of this page, System D is not such a system, in any context, and it does not become one if true rules that keep the term are added, inclusions among them. The reason is the SN condition of {{typeset}}, through the word “safe” in the closure condition. Whether rules of another shape make a complete system is open.

Remark · Where completeness holds

Quoted from van Bakel’s survey and from the paper of Dezani, Honsell and Alessi; the papers of Barendregt, Coppo and Dezani and of Hindley that they report were not read for this page. The system of Barendregt, Coppo and Dezani has the type expressions of System D and one more, ω. Its rules are those of System D, a rule that gives every term the type expression ω, and a rule of subtyping for a relation ≤ between type expressions that contains, among others, the law same input of {{andlaws}} and the rule that a smaller input and a larger result give a larger arrow. In van Bakel’s words, ω “is used to type those sub-terms that disappear during reduction, and that cannot be typed from the current context”.

Its semantics is called the simple semantics. Take any model of the untyped λ-calculus: a set with an application, in which every term has a meaning and convertible terms have the same meaning. A variable of type expressions may stand for any subset of the model. A → B names the members that send every member of the set of A into the set of B, as ⇒ does here; ∧ names the intersection; ω names the whole model. A judgment is true if it holds in every model, for every choice of subsets. The theorem of 1983: in that system a judgment is derivable if and only if it is true. The proof builds one model out of the type expressions themselves. The rule of subtyping is there for the sake of this theorem: completeness forces the law same input and the rule for arrows, and the example that shows it for the law is the one of {{andlaws}}. With ω the derivable judgments are also closed under conversion of the term, in both directions. For the simple types, with arrows only, Hindley proved a completeness theorem in the same year; its exact form was not checked for this page.

The literature names two more readings of the arrow, for the same models. In the F-semantics only the meanings of abstractions count as members of an arrow. In the inference semantics any set between the two may serve. The paper of Dezani, Honsell and Alessi says for each of the three which relations ≤ give a complete system.

Measured against this page. That semantics differs from the one here in three ways. A set there is any subset: nothing like the SN condition bounds it, and the empty set and the whole model are allowed. No member is in every set: there is no Base condition, so a hypothesis x : A carries information that the variable x does not have by itself. And a set is closed under conversion, because convertible terms are one member of the model. Each of the three gives up something that strong normalization needs. If the empty set may be the value of a variable, then membership says nothing about strong normalization, by narrow point 2 in {{simpler}}. Without the Base condition a variable cannot be replaced by itself, which is how {{rules}} gets C1 for terms with free variables. And no type set is closed under conversion, as {{equality}} showed. The lemma that follows shows the other side: with the SN condition kept, a set for ω cannot exist, and the work that ω does is left undone.

Definition · A rule that keeps the term

A rule keeps the term if it concludes a judgment about a term from one or more judgments about the same term.

The rules “∧ in”, “∧ out”, “∀ in”, “∀ out” and every rule of subtyping keep the term. The rules “variable”, “→ in” and “→ out” do not.

Lemma · True, and not derivable by rules that keep the termhere, unreviewed

Let X and W be variables of type expressions.

true
The judgment x : X ⊨ (λc.I) (λb.x b) : W → W is true.
no true part
For no type expression C of System D is the judgment x : X ⊨ λb.x b : C true.
not derivable
Take the rules “variable”, “→ in” and “→ out”, and with them any rules that keep the term and are true, for the type expressions of System D. Then no judgment Γ ⊢ (λc.I) (λb.x b) : F is derivable in which Γ gives x the type expression X.

The term is strongly normalizing, so it is typable in System D, by {{andsn}}: with x : Z → Z′, for instance. With x : X it gets no type expression at all, although it is a member of ρ(W) ⇒ ρ(W) whatever member of ρ(X) is put for x. The reason is in the head step that discards the argument λb.x b. The closure condition asks of a discarded argument only that it is in SN: that is the word “safe”. A rule can ask only that the argument has a type expression. And λb.x b is strongly normalizing for every member of ρ(X) put for x, while no type expression is true of it. This is the example “The discarded argument has to be typable” of {{andsn}}, seen from the side of truth. It is also the place of ω in the system of Barendregt, Coppo and Dezani: there the discarded argument gets ω, and ω names a set that contains every term. No type set contains every term.

Proof

A strongly normalizing term applied to a variable is strongly normalizing. Let u ∈ SN and let b be a variable, and take any run from u b. Its steps are steps inside u, until the run reduces a redex (λa.s) b, if it ever does, where λa.s is a term that u reaches. The run then continues from s[b/a]. Now s ∈ SN, by R1 (subterms), and replacing a variable by a variable neither creates nor removes a redex, so the runs of s[b/a] are the runs of s with b in the place of a, and they are finite. So the run is finite either way. This is the converse of the fact applied to a variable of {{good}}.

True. Fix ρ and take u ∈ ρ(X). Then u ∈ SN, by the SN condition, so u b ∈ SN, and λb.u b ∈ SN, because every step of an abstraction is a step inside it. The term (λc.I) (λb.u b) takes a head step to I, and the step is safe. I ∈ ρ(W) ⇒ ρ(W), by {{ops}}. So (λc.I) (λb.u b) ∈ ρ(W) ⇒ ρ(W), by the closure condition.

No true part. A type expression of System D is built by ∧ from variables and arrows, and if the judgment were true for C1 ∧ C2, it would be true for C1. So it is enough to refute it for a variable and for an arrow.

A variable V, which may be X itself. Send every variable of type expressions to Min, and replace x by itself, which is a member of Min. The term λb.x b is an abstraction, and no abstraction is in Min, by M2 (generated): an abstraction has no head step and is not in Base.

An arrow B → C′. Let n be the number of arrows in B. Send every variable of type expressions to SN. Write wm for λv1.…λvm.I, with m abstractions in front of I. First, wm is in the set of every type expression A′ of System D with at most m arrows, by induction on A′. A variable names SN, and wm is a normal form. For A1 ∧ A2 both parts have at most m arrows. For A1 → A2, m ≥ 1 and A2 has at most m − 1 arrows; if a is in the set of A1, then wm a takes a safe head step to wm−1, which is in the set of A2 by induction, and the closure condition applies. So wn is in the set of B. Second, let u = λa. a I…I δ δ, with n copies of I. It is a normal form, so it is in SN = ρ(X). And (λb.u b) wn → u wn → wn I…I δ δ, which reaches I δ δ by n steps, and then δ δ = Ω. So (λb.u b) wn is not in SN, and so not in the set of C′; and λb.u b is not in the set of B → C′.

Not derivable. One fact about derivations is used. If Γ ⊢ s v : F is derivable by the rules named, then Γ ⊢ v : A is derivable for some A. By induction on the derivation: if the last rule is “→ out”, the judgment about v is above it; if the last rule keeps the term, a judgment about s v is above it, and the induction applies; and “variable” and “→ in” do not conclude a judgment about an application.

Suppose Γ ⊢ (λc.I) (λb.x b) : F is derivable, with x : X in Γ. By the fact, Γ ⊢ λb.x b : A is derivable for some A. Every rule used is true: the three rules of System D by {{rules}}, the others by assumption. So Γ ⊨ λb.x b : A is true. Replace every variable of Γ other than x by itself, which the Base condition allows. What is left says that x : X ⊨ λb.x b : A is true, against the item no true part.

The claims about particular terms were checked by a program that searches all runs, for n up to 3. ∎

Remark · What this does and does not show

It shows that the incompleteness of {{true}} is not an accident of System F, of the context or of missing inclusions: it is there for the smallest system on this page that types every strongly normalizing term, in every context that declares the free variable, and for every extension of that system by true rules that keep the term. And it shows where it comes from. The SN condition makes membership in a type set a fact about the term that holds whatever type expression is used, and the closure condition uses that fact for a discarded argument without asking for a type expression. A semantics in which sets are not bounded by SN can give the discarded argument the set of all terms, and that is the semantics for which completeness is proved.

It does not show that no rule could be added. A rule of another shape derives this judgment. With the existential types of {{more}}, the type expression ∃Z.Z names SN, the union of all type sets. The rule that concludes Γ ⊢ λb.t b : ∃Z.Z from Γ ⊢ t : A, for a variable b that is not free in t, is true, by the first paragraph of the proof; it does not keep the term. With it, x : X ⊢ λb.x b : ∃Z.Z is derivable, and then the judgment of the lemma, by “→ in” and “→ out”. Whether some finite list of true rules derives every true judgment of System D was not looked at. From general knowledge, not checked against sources for this page: for sets of terms closed under undoing head steps, completeness has been proved for restricted classes of type expressions, by Labib-Sami and by Farkh and Nour for System F and by Kamareddine and Nour for intersection types.
