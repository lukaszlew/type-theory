The soundness theorem says that every derivable judgment is true. {{true}} showed that the converse fails, and every example so far could be repaired. The lemma “True and not derivable” is repaired by giving its variable a place in the context; its sharper case by ∧, with which every strongly normalizing term is typable ({{andsn}}); the law of {{andlaws}} by adding inclusions as rules. This section asks what is left after such repairs. For another semantics of sets the literature has a system of rules that derives exactly the true judgments, and it is quoted first. The proof of that theorem carries over from models to sets of terms that are closed under undoing every head step, and a lemma states it. For the type sets of this page, System D is not such a system, even for a judgment whose context declares every free variable of the term, and it does not become one if true rules that keep the term are added, inclusions among them. The reason is the SN condition of {{typeset}}, through the word “safe” in the closure condition. Whether rules of another shape make a complete system is open.

Remark · Where completeness holds

Quoted from van Bakel’s survey and from the paper of Dezani, Honsell and Alessi; the papers of Barendregt, Coppo and Dezani and of Hindley that they report were not read for this page. The system of Barendregt, Coppo and Dezani has the type expressions of System D, the system of {{andsn}}, and one more, ω. Its rules are those of System D, a rule that gives every term the type expression ω, and a rule of subtyping for a relation ≤ between type expressions that contains, among others, the law same input of {{andlaws}} and the rule that a smaller input and a larger result give a larger arrow. In van Bakel’s words, ω “is used to type those sub-terms that disappear during reduction, and that cannot be typed from the current context”.

Its semantics is called the simple semantics. Take a model of the untyped λ-calculus, of the kind that the survey calls a continuous λ-model: a set with an application, in which every term has a meaning and convertible terms, in the sense of {{equality}}, have the same meaning. A variable of type expressions may stand for any subset of the model. A → B names the members that send every member of the set of A into the set of B, as ⇒ does here; ∧ names the intersection; ω names the whole model. A judgment is true if it holds in every model, for every choice of subsets. The theorem of 1983: in that system a judgment is derivable if and only if it is true. The proof builds one model out of the type expressions themselves. The rule of subtyping is there for the sake of this theorem: if ∧ may stand to the right of an arrow, completeness forces the law same input and the rule for arrows, and the example that shows it for the law is the one of {{andlaws}}; in van Bakel’s own systems, where it may not, the rule for arrows is enough. With ω the derivable judgments are also closed under conversion of the term, in both directions. For the simple types, with arrows only, completeness follows from that theorem, as Barendregt, Coppo and Dezani showed, and Hindley proved it in the same year for several readings of the arrow; the exact form of his theorem was not checked for this page. Dezani, Honsell and Alessi show what completeness without ω costs: System D with a rule of subtyping, for the relation generated by the laws of ∧, the law same input and the rule for arrows, is complete for the simple semantics taken over a wider class of structures, in which a step that discards an argument need not keep the meaning. Over the models described here it is not complete: y : A ⊨ (λx.y) Ω : A is true in every one of them, because the term is convertible with y, and it is not derivable, because Ω has no type expression without ω.

The literature names two more readings of the arrow, for the same models. In the F-semantics only the meanings of abstractions count as members of an arrow. In the inference semantics the members that may count as functions form any set between the two, and a judgment is true if it holds for every such set. The paper of Dezani, Honsell and Alessi says for each of the three which relations ≤ give a complete system.

Measured against this page. That semantics differs from the one here in three ways. A set there is any subset: nothing like the SN condition bounds it, and the empty set and the whole model are allowed. No member is in every set: there is no Base condition, so a hypothesis x : A carries information that the variable x does not have by itself. And a set is closed under conversion, because convertible terms are one member of the model. Each of the three gives up something that strong normalization needs. If the empty set may be the value of a variable, then membership says nothing about strong normalization, by narrow point 2 in {{simpler}}. Without the Base condition a variable cannot be replaced by itself, which is how {{rules}} gets C1 for terms with free variables. And no type set is closed under conversion, as {{equality}} showed. The lemma “True, and not derivable by rules that keep the term” of this section shows the other side: with the SN condition kept, a set for ω cannot exist, and the work that ω does is left undone.

The theorems just quoted are about models. The same proof can be run on sets of terms, and it says which of the three conditions of {{typeset}} stand in the way.

Definition · Expansion-closed set

A set T of terms is expansion-closed if the following holds: if s →h s′ and s′ ∈ T, then s ∈ T, for every head step, safe or not.

The empty set and the set of all terms are expansion-closed. No type set is: y is in every type set, and (λx.y) Ω, which takes a head step to it, is in none.

Definition · The essential system

The essential system is van Bakel’s. Its type expressions come in two layers: A ::= X | S → A and S ::= A1 ∧ … ∧ An with n ≥ 0; ω is the case n = 0. So ∧ stands only to the left of an arrow or outermost.

The relation ≤ is the least relation that is reflexive and transitive and has: A1 ∧ … ∧ An ≤ Ai; if S ≤ Ai for every i, then S ≤ A1 ∧ … ∧ An; and if S′ ≤ S and A ≤ A′, then S → A ≤ S′ → A′.

A context gives each of its variables an S. The rules:

rulefromconclude
variablex:S is in Γ, and S ≤ AΓ ⊢ x : A
→ inΓ, x:S ⊢ t : AΓ ⊢ λx.t : S → A
→ outΓ ⊢ t : S → A and Γ ⊢ u : SΓ ⊢ t u : A
∧ inΓ ⊢ t : Ai for each i from 1 to n, with n ≥ 0Γ ⊢ t : A1 ∧ … ∧ An

With n = 0 the rule “∧ in” gives every term the type expression ω.

Definition · The reading over expansion-closed sets

In the reading over expansion-closed sets, a variable of type expressions stands for an expansion-closed set of terms, → is read as ⇒, ∧ as ∩, and ω as the set of all terms.

A judgment Γ ⊢ t : S of the essential system is true in that reading if the following holds for every choice of expansion-closed sets for the variables of type expressions: if each variable x:S′ of Γ is replaced in t by a member of the set of S′, then the result is in the set of S.

This is the definition of a true judgment in {{judg}}, with expansion-closed sets in the place of type sets. A variable of type expressions may stand for the empty set. The term may have free variables that the context does not declare; they are not replaced.

Lemma · Complete, for expansion-closed setshere, reviewed

A judgment of the essential system is derivable if and only if it is true in the reading over expansion-closed sets. The term of the judgment may have free variables that its context does not declare.

The proof is the proof of the completeness theorems quoted in the remark, run on terms: the model is made of the terms themselves, and the set that a variable X stands for is the set of terms that the rules give X, in one fixed context. That is the set that {{cmpsem}} calls missing from its list. It was worked out for this page by a reader of van Bakel’s survey, from five facts that the survey proves; that reader names Hindley for the method, from general knowledge, and the papers of Hindley were not read. The proof shows where each condition of {{typeset}} would stop it. With the Base condition, the set for X would have to contain the variables that the context declares otherwise. With the SN condition, it could not be closed under undoing a head step that discards a term outside SN, and the rules of this system do undo such steps: (λx.y) Ω has every type expression that y has, because Ω has ω. The closure condition, read for every head step, is the one condition of the three that completeness lives with.

Proof

Quoted from van Bakel’s survey, for the essential system. Parts: if Γ ⊢ t : A1 ∧ … ∧ An is derivable, so is each Γ ⊢ t : Ai; and a variable that is not free in the term may be removed from the context. One argument less: if Γ, z:S ⊢ t z : A is derivable and z is not free in t, then Γ ⊢ t : S → A is derivable. Conversion: if Γ ⊢ t : S is derivable and t and t′ are convertible, then Γ ⊢ t′ : S is derivable. More variables: a derivation stays a derivation if declarations are added to the context. ω alone: if Γ gives x the type expression ω, or does not declare x, then Γ ⊢ x : S is derivable only for S = ω.

Derivable implies true. Every type expression names an expansion-closed set: for the arrow, if s →h s′, s′ ∈ T ⇒ U and u ∈ T, then s u →h s′ u and s′ u ∈ U, so s u ∈ U. If S ≤ S′, then the set of S is inside the set of S′, by induction on the definition of ≤; the three clauses are facts about ∩ and ⇒. Then by induction on the derivation. “Variable” is the inclusion. “→ in”: (λx.t) u takes a head step to t[u/x], and the set is expansion-closed. “→ out” is the definition of ⇒. “∧ in” is the definition of ∩, and for n = 0 every term is in the set of all terms.

True implies derivable. Let Γ ⊨ t : S be true. Choose a function Γ∞ from all term variables to type expressions S that agrees with Γ on the variables of Γ, gives ω to the other free variables of t, and gives every S to infinitely many variables. Write C(S′) for the set of terms s for which a finite part of Γ∞ derives s : S′.

Each C(S′) is expansion-closed, by conversion. So the assignment ρ(X) = C(X) is allowed. Under it every S′ names C(S′), by induction on S′. For a variable X: by the choice of ρ. For ∧: by “∧ in”, after the finite parts have been put together by more variables, and by parts; for n = 0 both sets are the set of all terms. For S′ → A: a member of C(S′ → A) sends C(S′) into C(A), by more variables and “→ out”. In the other direction, let s send the set of S′ into the set of A. Choose a variable z that Γ∞ gives S′ and that is not free in s. Then z ∈ C(S′), so s z ∈ C(A): a finite part of Γ∞ derives s z : A, and by more variables it may be taken to contain z:S′. By one argument less, the rest of that part derives s : S′ → A.

Each variable x:S′ of Γ is in C(S′), which is the set of S′. So replace every variable of Γ by itself: because the judgment is true, t is in the set of S, which is C(S). So a finite part of Γ∞ derives t : S. By parts, the variables that are not free in t can be removed from it. A free variable of t that is not in Γ has ω there; by ω alone the derivation gives it only ω, which it has without being declared, so its declaration can be removed too, by induction on the derivation. What is left is a part of Γ, and more variables gives the judgment in Γ. ∎

Lemma · What the complete semantics proves of a typable termhere, reviewed

A head normal form is a term λx1.…λxk. y u1…un, with k ≥ 0 and n ≥ 0 and any terms ui. A term is head normalizing if it reaches a head normal form by steps. For the essential system:

head
If Γ ⊢ t : A is derivable, for a type expression A of the first layer, so not ω, then t is head normalizing.
normal
If Γ ⊢ t : S is derivable and ω occurs neither in Γ nor in S, so that S has at least one part, then t is weakly normalizing.
not strong
y : X ⊢ (λx.y) Ω : X is derivable, ω occurs neither in its context nor in its type expression, and the term is not in SN.

So the semantics that is complete pays for it in what it proves: head normalization and weak normalization, and not strong normalization. The proof is a variant of the move of {{good}}: the sets are expansion-closed sets inside a set Good, which is the set of head normalizing terms for the first item and the set of weakly normalizing terms for the second. It is a variant because the sets are closed under undoing every head step and not only the safe ones, and because for the first item the set that every one of them contains has variables applied to any arguments. With Good = SN it does not start, because SN is not expansion-closed: that is narrow point 3. Quoted from van Bakel’s survey: the two items are halves of characterizations that the survey proves by another method and gives as Coppo, Dezani and Venneri’s: a term is head normalizing if and only if it has a type expression of the first layer, and it has a normal form if and only if it has a type expression in which, as in the context, ω does not occur. The proof given here was found by a reader of the survey for this page and checked by the writer.

Proof

Let Good be the set of head normalizing terms, or the set of weakly normalizing terms. Write B for the set of the terms x u1…un, with any terms ui in the first case and with weakly normalizing ui in the second. Call a set a Good-set if it is expansion-closed, is inside Good and contains B.

Good is a Good-set: undoing a head step is undoing a step, and the members of B are head normal forms in the first case and have normal forms in the second.

If t x ∈ Good for a variable x that is not free in t, then t ∈ Good. For the weakly normalizing terms this is shown in {{good}}, with the standardization theorem quoted there; to quote no theorem, take for Good the set WN of the lemma “Weak normalization with no theorem quoted” of {{good}}, which is expansion-closed by its rule for head steps and has the property applied to a variable by that lemma. For the head normalizing terms, take a run from t x to a head normal form h. If no step of it reduces a redex (λy.s) x made of the whole term, then h is t′ x for a term t′ that t reaches, and t′ is a variable applied to arguments, so a head normal form. If one does, then t reaches λy.s and s[x/y] reaches h; x is not free in s, because a step adds no free variable, so λy.s is the same term as λx.s[x/y], which reaches λx.h, a head normal form.

If T contains every variable and U is a Good-set, and in the second case T is inside Good, then T ⇒ U is a Good-set. It is expansion-closed, by the argument for the arrow in the proof of the lemma “Complete, for expansion-closed sets”. It is inside Good, by the fact just shown, with a variable for the argument. And a member of B applied to a member of T is in B.

Head. Send every variable of type expressions to the set of head normalizing terms. By induction, a type expression of the first layer names a Good-set, and one of the second layer names a set that contains every variable: an intersection of Good-sets, or the set of all terms. The judgment is true in the reading over expansion-closed sets, by the lemma “Complete, for expansion-closed sets”. Replace each variable of Γ by itself. Then t is in the set of A, which is inside Good.

Normal. Send every variable of type expressions to the set of weakly normalizing terms. By induction, a type expression of either layer in which ω does not occur names a Good-set: a variable names Good; an intersection of one or more Good-sets is a Good-set; and for S′ → A the claim on T ⇒ U applies, because the set of S′ is a Good-set, so it contains every variable and is inside Good. A Good-set contains B, so every variable. So each variable of Γ may be replaced by itself, a free variable of t that Γ does not declare is not replaced, and t is in the set of S, which is inside Good. Type expressions with ω may occur inside the derivation; the lemma “Complete, for expansion-closed sets” covers them, because it is used for the whole derivation at once.

Not strong. x:ω, y:X ⊢ y : X by the variable rule, so y:X ⊢ λx.y : ω → X; Ω has ω; and “→ out” gives the judgment. ∎

Definition · A rule that keeps the term

A rule keeps the term if it concludes a judgment Γ ⊢ t : B from one or more judgments Γ ⊢ t : A1, …, Γ ⊢ t : An, with the same context and the same term.

The rules “∧ in”, “∧ out”, “∀ in”, “∀ out” and every rule of subtyping keep the term. The rules “variable”, “→ in” and “→ out” do not.

Lemma · True, and not derivable by rules that keep the termhere, reviewed

Let X and W be variables of type expressions.

true
The judgment x : X ⊨ (λc.I) (λb.x b) : W → W is true.
no true part
For no type expression C of System D is the judgment x : X ⊨ λb.x b : C true.
not derivable
Take the rules “variable”, “→ in” and “→ out”, and with them any rules that keep the term and are true, for the type expressions of System D. Then no judgment Γ ⊢ (λc.I) (λb.x b) : E is derivable in which Γ gives x the type expression X.

The term is strongly normalizing, so it is typable in System D, by {{andsn}}: with x : Z → Z′, for instance. With x : X it gets no type expression at all, although it is a member of ρ(W) ⇒ ρ(W) whatever member of ρ(X) is put for x. The reason is in the head step that discards the argument λb.x b. The closure condition asks of a discarded argument only that it is in SN: that is the word “safe”. A rule can ask only that the argument has a type expression. And λb.x b is strongly normalizing for every member of ρ(X) put for x, while no type expression is true of it. This is the example “The discarded argument has to be typable” of {{andsn}}, seen from the side of truth. It is also the place of ω in the system of Barendregt, Coppo and Dezani: there the discarded argument gets ω, and ω names a set that contains every term: λb.x b has ω by the rule for ω, λc.I has ω → (W → W), and “→ out” gives the judgment. No type set contains every term.

Proof

A strongly normalizing term applied to a variable is strongly normalizing. Let u ∈ SN and let b be a variable, and take any run from u b. Its steps are steps inside u, until the run reduces a redex (λa.s) b, if it ever does, where λa.s is a term that u reaches. The run then continues from s[b/a]. Now s ∈ SN, by R1 (subterms), and replacing a variable by a variable neither creates nor removes a redex, also if b is already free in s, so the runs of s[b/a] are the runs of s with b in the place of a, and they are finite. So the run is finite either way. This is the converse of the fact applied to a variable of {{good}}.

True. Fix ρ and take u ∈ ρ(X). Then u ∈ SN, by the SN condition, so u b ∈ SN, and λb.u b ∈ SN, because every step of an abstraction is a step inside it. The term (λc.I) (λb.u b) takes a head step to I, and the step is safe. I ∈ ρ(W) ⇒ ρ(W), by {{ops}}. So (λc.I) (λb.u b) ∈ ρ(W) ⇒ ρ(W), by the closure condition.

No true part. A type expression of System D is built by ∧ from variables and arrows, and if the judgment were true for C1 ∧ C2, it would be true for C1, because ∧ names ∩. So it is enough to refute it for a variable and for an arrow.

A variable V, which may be X itself. Send every variable of type expressions to Min, and replace x by itself, which is a member of Min. The term λb.x b is an abstraction, and no abstraction is in Min, by M2 (generated): an abstraction has no head step and is not in Base.

An arrow B → C′. Let n be the number of arrows in B. Send every variable of type expressions to SN. Write wm for λv1.…λvm.I, with m abstractions in front of I. First, for every m, wm is in the set of every type expression A′ of System D with at most m arrows, by induction on A′, for all m at once. A variable names SN, and wm is a normal form. For A1 ∧ A2 both parts have at most m arrows. For A1 → A2, m ≥ 1 and A2 has at most m − 1 arrows; if a is in the set of A1, then wm a takes a safe head step to wm−1, which is in the set of A2 by induction, and the closure condition applies. So wn is in the set of B. Second, let u = λa. a I…I δ δ, with n copies of I. It is a normal form, so it is in SN = ρ(X). And (λb.u b) wn → u wn → wn I…I δ δ, which reaches I δ δ by n steps, and then δ δ = Ω. So (λb.u b) wn is not in SN, and so not in the set of C′; and λb.u b is not in the set of B → C′.

Not derivable. One fact about derivations is used. If Γ ⊢ s v : E is derivable by the rules named, then Γ ⊢ v : A is derivable for some A. By induction on the derivation: if the last rule is “→ out”, the judgment about v is above it; if the last rule keeps the term, a judgment about s v is above it, and the induction applies; and “variable” and “→ in” do not conclude a judgment about an application.

Suppose Γ ⊢ (λc.I) (λb.x b) : E is derivable, with x : X in Γ. By the fact, Γ ⊢ λb.x b : A is derivable for some A. Every rule used is true: the three rules of System D by {{rules}}, the others by assumption. So Γ ⊨ λb.x b : A is true. Replace every variable of Γ other than x by itself, which the Base condition allows. What is left says that x : X ⊨ λb.x b : A is true, against the item no true part.

The claims about particular terms were checked by a program that searches all runs, for n up to 3. ∎

Remark · What this does and does not show

It shows that the incompleteness of {{true}} is not an accident of System F, of the context or of missing inclusions: it is there for the smallest system on this page that types every strongly normalizing term, for a judgment whose context declares every free variable of the term, and for every extension of that system by true rules that keep the term. And it shows where it comes from. The SN condition makes membership in a type set a fact about the term that holds whatever type expression is used, and the closure condition uses that fact for a discarded argument without asking for a type expression. A semantics in which sets are not bounded by SN can give the discarded argument the set of all terms, and that is the semantics for which completeness is proved.

It does not show that no rule could be added. A rule of another shape derives this judgment. With the existential types of {{more}}, the type expression ∃Z.Z names SN, the union of all type sets. The rule that concludes Γ ⊢ λb.t b : ∃Z.Z from Γ ⊢ t : A, for a variable b that is not free in t, is true, by the SN condition and the fact that opens the proof of the lemma, that a strongly normalizing term applied to a variable is strongly normalizing. It does not keep the term, and its type expression is not one of System D. With it, x : X ⊢ λb.x b : ∃Z.Z is derivable, and then the judgment of the lemma, by “→ in” and “→ out”. Whether some finite list of true rules derives every true judgment of System D was not looked at. From general knowledge, not checked against sources for this page: for sets of terms closed under undoing head steps, completeness has been proved for restricted classes of type expressions, by Labib-Sami and by Farkh and Nour for System F and by Kamareddine and Nour for intersection types.
