The first addition is the intersection of two type sets, with the name A ∧ B. It gets this section and the two after it, for three reasons. An argument that is used in two ways can be given a type expression for each use. ∧ is the finite form of ∀. And with ∧ the rules reach every strongly normalizing term, which the rules of System F do not.

Definition · The intersection of two type expressions

There is one more form of type expression: A ∧ B. An example is X ∧ (X → Y).

One clause is added:

⟦A ∧ B⟧ρ = ⟦A⟧ρ ∩ ⟦B⟧ρ

Two rules are added:

RuleFromConclude
∧ inΓ ⊢ t : A and Γ ⊢ t : BΓ ⊢ t : A ∧ B
∧ outΓ ⊢ t : A ∧ BΓ ⊢ t : A, and also Γ ⊢ t : B

System F with ∧ has the five rules of System F and these two rules.

System D has the five rules “variable”, “→ in”, “→ out”, “∧ in” and “∧ out”. Its type expressions are built from variables with → and ∧. It has no ∀. The name is Krivine’s.

For each of the two systems, a derivation uses the rules of that system, and “derivable” and “typable” are defined from derivations as in {{rules}}.

The term is the same above and below each of the two rules. A term with the type expression A ∧ B is not a pair of two terms. It is one term, and the rules give it A and also B.

A ∧ B names the intersection of two type sets, the two that A and B name. ∀X.A names an intersection over all type sets. So ∧ brings no new operation on sets. It is ∩ again, over two sets and not over all of them.

Lemma · The intersection of two type setshere, reviewed

Let T and U be type sets.

type set
T ∩ U is a type set.
∧ in
If t ∈ T and t ∈ U, then t ∈ T ∩ U.
∧ out
If t ∈ T ∩ U, then t ∈ T and t ∈ U.

So, by the addition lemma of {{price}}, Lemma N, the soundness theorem and both corollaries hold for System F with ∧.

The soundness theorem and C1 (strong normalization) hold for System D, because a derivation of System D is a derivation of System F with ∧. System D has no ∀, and C2 (consistency) reads there: no closed term t has ⊢ t : X for a variable X.

Proof

Type set. This is the intersection lemma of {{ops}}, with the index set {1, 2} and F(1) = T, F(2) = U.

∧ in and ∧ out are the definition of ∩.

The addition lemma. The clause computes ⟦A ∧ B⟧ρ from the two sets that its parts name, by ∩, which gives a type set by the first part. So Lemma N holds. The two rules are true: fix ρ, and replace the variables of the context by members of the type sets that their type expressions name. If the term that results is in ⟦A⟧ρ and in ⟦B⟧ρ, then it is in ⟦A ∧ B⟧ρ, which is “∧ in”; if it is in ⟦A ∧ B⟧ρ, then it is in both, which is “∧ out”.

C2 in System D. Send X to Min. A closed term t with ⊢ t : X would be a closed member of Min, and by M3 (smallest) there is none. ∎

Example · The intersection of no type sets is not a type set

Many presentations of intersection types have one more type expression, ω, with the rule that Γ ⊢ t : ω for every Γ and every t. It stands for the intersection of no type expressions.

For this rule to be true, ω has to name a set that contains every term. No type set does, because Ω ∉ SN. And with the rule, y : ω → X ⊢ y Ω : X is derivable, although y Ω ∉ SN.

So this rule cannot be added. It is the reason why the intersection lemma of {{ops}} asks for a nonempty collection.

Quoted from the literature: with ω and its rule, a term is weakly normalizing if and only if it is typable in such a way that ω does not occur in the context or in the type expression of the term.
