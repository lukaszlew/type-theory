Narrow point 5 · ∀ over type expressions

Goal
Say which set of terms ∀X.A names.
Try
Let C run over type expressions and not over sets. In System F a term with the type expression ∀X.A may be used at A[B/X] for any type expression B. So let ∀X.A name the terms that are in the set named by A[B/X], for every type expression B.
Breaks
The definition is circular. The set that a type expression names is defined from the sets that shorter type expressions name. But B may be ∀X.A itself, or something longer. With A = X → X and B = ∀X.X→X, the instance (∀X.X→X) → (∀X.X→X) contains the type expression being defined, twice.
Hence
The definition of names lets C run over all type sets in the sense of {{typeset}}. Those are sets, and the collection of them was fixed by the three conditions before ⇒ or ∀ were mentioned. So it is one intersection of sets that already exist. The result is again a type set, and so it is one of the sets it was intersected over. So the definition is impredicative, in the sense of {{ops}}. Ordinary set theory allows it. Predicative foundations do not, and this is the one place where the proof needs a strong metatheory, that is, a strong theory to carry the proof out in. The idea is Girard’s.

Lemma · Most type sets have no namehere, reviewed

There are countably many type expressions and uncountably many type sets. So almost every type set is named by no closed type expression.

Proof

A type expression is a finite string of symbols, so there are countably many. For the type sets, let S be any set of closed normal forms, and take the type set Gen(S) of {{typeset}}. Its closed normal forms are exactly the members of S: members of Min have free variables, and what the closure condition adds always has a head step. So different S give different type sets, and there are uncountably many sets S. ∎

So a variable X ranges over far more than type expressions can name. Type sets built by hand, like TI in {{typeset}}, are legitimate values for X. No rule mentions them, yet every member of the set that ∀X.X→X names has to send each of them into itself.
