In System F the soundness theorem has no converse, even for typability alone: some strongly normalizing terms are not typable, as quoted in {{true}}. With ∧ that changes.

Characterization theorem · Which terms are typable with ∧known, proof here

For every term t, the following three statements are equivalent.

SN
t is strongly normalizing.
D
t is typable in System D.
F with ∧
t is typable in System F with ∧.

So the set of terms that are typable in System D is SN, the largest type set.

The theorem is a known result, and so is the route of the proof, induction on the three rules of the generation lemma. The text of the proof is this page’s.

Proof

From D to F with ∧. A derivation of System D is a derivation of System F with ∧.

From F with ∧ to SN. This is C1 (strong normalization) for System F with ∧.

From SN to D. By the generation lemma of {{gen}}, it is enough to show that the set of terms that are typable in System D is closed under the three rules of that lemma. The proof uses three standard facts about the derivations of System D. Each is proved by a routine induction on the derivation, which is omitted.

  • More variables. If Γ ⊢ t : A, and Δ contains every x:B of Γ, in any order, then Δ ⊢ t : A.
  • Fewer variables. If Γ ⊢ t : A, and y is not free in t, then Γ without y also derives t : A.
  • Stronger variables. If Γ ⊢ t : A, and Δ is Γ with one x:B replaced by x : B ∧ C or by x : C ∧ B, then Δ ⊢ t : A.

For two contexts Γ and Γ′, write Γ ∧ Γ′ for a context that has the variables of both. A variable with B in Γ and B′ in Γ′ has B ∧ B′ in it. By more variables and stronger variables, every judgment that Γ derives, and every judgment that Γ′ derives, Γ ∧ Γ′ derives too.

Variable applied. Let Γi ⊢ ui : Ai for each i. Let Γ be Γ1 ∧ … ∧ Γn joined in the same way with the context x : A1 → … → An → Y. Then Γ ⊢ x : A1 → … → An → Y and Γ ⊢ ui : Ai, and n uses of “→ out” give Γ ⊢ x u1…un : Y.

Abstraction. Let Γ ⊢ t : B. If x is not in Γ, add x : X. Move x : A to the end of the context. Then “→ in” gives λx.t the type expression A → B.

Head step, without trailing arguments. Let Γ ⊢ t[u/x] : A and Γ′ ⊢ u : B, with x chosen so that it is not in Γ, not in Γ′ and not free in u. The claim is that there is a type expression B′ with

Γ ∧ Γ′ ⊢ u : B′  and  Γ ∧ Γ′, x:B′ ⊢ t : A

Then “→ in” and “→ out” give Γ ∧ Γ′ ⊢ (λx.t) u : A. The claim is proved by induction on the derivation of Γ ⊢ t[u/x] : A, for all Γ, t and A at once.

  • If t is x, then t[u/x] is u. Take B′ = A.
  • If x is not free in t, then t[u/x] is t. Take B′ = B. This is the only place where the proof uses that u is typable.
  • Otherwise t is an application or an abstraction, and the last rule of the derivation is not the variable rule.
    • “∧ in”, with A = A1 ∧ A2. The induction gives B1 for A1 and B2 for A2. Take B′ = B1 ∧ B2.
    • “∧ out”. The induction gives a B′ for the judgment above the rule, and the same B′ serves.
    • “→ out”, with t = t1 t2. The induction gives B1 for t1 and B2 for t2. Take B′ = B1 ∧ B2.
    • “→ in”, with t = λy.t1 and y chosen so that it is not in Γ′ and not free in u. The judgment above the rule is Γ, y:A1 ⊢ t1[u/x] : A2. The induction gives a B′, with u : B′ derived in a context that contains y. Fewer variables removes y from that context. Then “→ in” gives λy.t1 its type expression.

Where two type expressions B1 and B2 are replaced by B1 ∧ B2, “∧ in” gives u : B1 ∧ B2, and stronger variables keeps the judgments about t derivable.

Head step, with trailing arguments. Let Γ ⊢ t[u/x] u1…un : C with n ≥ 1, and Γ′ ⊢ u : B. The claim is that Γ ∧ Γ′ ⊢ (λx.t) u u1…un : C. It is proved by induction on the derivation. If the last rule is “∧ in” or “∧ out”, the induction applies to the judgments above it, which are about the same term. Otherwise the last rule is “→ out”, from Γ ⊢ t[u/x] u1…un−1 : A′ → C and Γ ⊢ un : A′. By induction, or by the case without trailing arguments if n = 1, Γ ∧ Γ′ ⊢ (λx.t) u u1…un−1 : A′ → C. Then “→ out” gives the claim. ∎

The proof needs ∧ wherever one thing has to serve several uses. There are two such places. If two contexts are joined, then a variable that both contain gets both type expressions. And if a head step is undone, then the copies of the argument u inside t[u/x] may have received different type expressions B1,…,Bk, one for each copy. Before the step there is one u, and it gets B1 ∧ … ∧ Bk. The example with δ I in {{and}} shows this for two copies.

If there is no copy, because the head step threw u away, then the derivation for t[u/x] says nothing about u, and u has to be typable by assumption. This is the safe head step of {{head}} again, with “typable” in the place of “in SN”. So the proof follows the definition of a type set: its case “variable applied” matches the Base condition, and its case “head step” matches the closure condition.

Example · The discarded argument has to be typable

The head step (λx.y) (I I) →h y discards its argument. A derivation in System D for the term before the step:

LineJudgmentRule
1y : X, x : Y→Y ⊢ y : Xvariable
2y : X ⊢ λx.y : (Y→Y) → X→ in, from 1
3y : X ⊢ I : (Y→Y) → (Y→Y)variable, → in
4y : X ⊢ I : Y→Yvariable, → in
5y : X ⊢ I I : Y→Y→ out, from 3 and 4
6y : X ⊢ (λx.y) (I I) : X→ out, from 2 and 5

The derivation for y alone is line 1 without x. It says nothing about I I, and lines 3 to 5 have to be supplied from the assumption that the argument is typable. In the proof this is the case “x is not free in t”, with Γ′ empty and B′ = Y→Y; there, more variables is what moves ⊢ I I : Y→Y under the context y : X, which the example avoids by deriving lines 3 to 5 under y : X directly. With Ω in the place of I I there would be no line 5, and (λx.y) Ω is indeed not in SN.

Three things the theorem does not say.

  • It is about typability, NOT about every true judgment. It says that a strongly normalizing term has some type expression in some context. It does not say that every true judgment is derivable. The lemma “True and not derivable” of {{true}} still holds with ∧, and so does the law that is true and not derivable, in {{andlaws}}.
  • It does not make System F easier. System D has no ∀, so its soundness needs no intersection over all type sets, and the impredicative definition of narrow point 5 does not occur. To get the strong normalization of System F from System D, one would have to show that every term that is typable in System F is typable in System D. By the theorem, that is the same as showing that it is strongly normalizing.
  • It gives no way to find a derivation. No program decides whether a term is strongly normalizing. That is a standard fact, quoted here. So, by the theorem, no program decides whether a term is typable in System D. A derivation that is given can still be checked line by line.
