There is a way of giving System F a meaning in which a type expression names the terms that pass every test in some set of tests, and in which the conditions of a type set are never stated, because they follow. It is the form used for classical logic and, from general knowledge, for languages with effects, where a test is a continuation, that is, a whole context waiting for the term: {{classical}} quotes the papers read for classical logic, and the remark “What tests are for” reports Pitts’s use of the construction for pairs of terms in a language with recursion. The sets themselves are in the literature under the name biorthogonals: Riba, in a paper read for this page, lists them with Tait’s saturated sets and Girard’s candidates as the three kinds of sets that proofs of this sort use, and cites Parigot’s paper of 1997 on strong normalization for classical natural deduction for them. This section makes it exact for the simplest kind of test, an argument list, and places the sets it produces in the chain of {{families}}. {{mu}} and {{classical}} then take the step to classical logic, where the rule for the new terms is false over all type sets and true over the sets of this section.

Definition · Tests, and the sets they define

A test is a finite list v1,…,vn of strongly normalizing terms, with n ≥ 0. A test is written v⃗ for short, and t v⃗ is t v1…vn.

A term t passes the test v⃗ if t v⃗ ∈ SN, and fails it otherwise. The empty test is passed by every strongly normalizing term.

For a nonempty set P of tests, P⊥ is the set of terms that pass every test in P.

A set of terms is test-defined if it is P⊥ for some nonempty set P of tests.

Two clauses need a reason. The terms of a test are strongly normalizing because otherwise no term would pass it, by R1 (subterms), and P⊥ could be empty; the Base condition in the lemma on the fourth collection uses this clause. The set of no tests is excluded because every term passes all of its tests, and the set of all terms is not a type set. In the literature P⊥ is called the orthogonal of P, and a set of the form P⊥ a biorthogonal; because it is the orthogonal of its own orthogonal: write Q for the set of tests that every member of P⊥ passes; P ⊆ Q, so Q⊥ ⊆ P⊥; and every member of P⊥ passes every test in Q by the definition of Q, so P⊥ ⊆ Q⊥. Riba defines both, for contexts of which argument lists are the case for β.

Lemma · One term passes every test, and every closed term fails onehere, reviewed

passes all
The term λx.y passes every test, so it belongs to every test-defined set. It is not in Min.
closed terms fail
For every closed term t there is a test v⃗ with t v⃗ ∉ SN.

The second part was found by an independent reader of this page and checked by its author; a program also ran the test it constructs on every closed normal form with at most ten symbols and reached Ω each time.

Proof

Passes all. The empty test: λx.y is a normal form, so it is in SN. A test v1,…,vn with n ≥ 1: (λx.y) v1 v2…vn →h y v2…vn is a head step, safe because v1 ∈ SN, and y v2…vn is in Base, so in SN by R2 (variable applied); so (λx.y) v⃗ ∈ SN by R3 (safe head step). And λx.y is not in Min, because every member of Min reaches a member of Base by head steps, by M2 (generated), while an abstraction has no head step and is not in Base.

Closed terms fail. If t ∉ SN, the empty test fails it. Let t ∈ SN. Some run from t ends in a normal form t̂, because every run is finite. t̂ is closed, because a step never adds a free variable. A closed normal form is an abstraction: by {{head}} it has one of three forms, a variable applied to arguments has a free variable, and an abstraction applied to arguments has a step. So t̂ = λx1.…λxk.s with k ≥ 1 and s not an abstraction; s is a normal form, as a subterm of one, so it is a variable applied to arguments, s = xi u1…um, and the variable is one of x1,…,xk because t̂ is closed. Take the test v1,…,vk,vk+1 with vj = I for j ≠ i and j ≤ k, with vi = λz1.…λzm.δ, which is δ itself if m = 0, and with vk+1 = δ. Each is a normal form, so in SN. Then t̂ v1…vk vk+1 reaches vi u1′…um′ δ by k head steps, where uj′ is uj with the vs put in for the xs; and that term reaches δ δ = Ω by m more head steps, because δ is closed and the substitutions for z1,…,zm change nothing in it. The terms uj′ need not be in SN; the run never looks inside them. So t̂ v⃗ reaches Ω, and it is not in SN, by R1 (subterms). The steps from t to t̂ are steps of t v⃗ as well, so t v⃗ reaches t̂ v⃗, and t v⃗ ∉ SN by R1 (subterms) again. ∎

Example · Three test-defined sets, and one set that is not

  • SN is test-defined: it is P⊥ for P the set containing only the empty test.
  • The set of terms that pass the test I alone is { t : t I ∈ SN }. It contains K, because K I → λy.I, and λx.x x x, because (λx.x x x) I → I I I → I I → I. It does not contain λx.x δ δ, because (λx.x δ δ) I → I δ δ → δ δ = Ω.
  • The set of terms that pass every test is test-defined, with P the set of all tests. It contains λx.y and no closed term, by the lemma before this example.
  • Min is not test-defined: every test-defined set contains λx.y, and Min does not.

Write TT for the collection of test-defined sets.

Lemma · Test-defined sets form a fourth collectionhere, reviewed

candidates
Every test-defined set is a reducibility candidate, so TT ⊆ CR, and the chain of {{families}} extends to TT ⊆ CR ⊆ HC ⊆ SAT.
strictly
TI is a candidate and is not test-defined. So TT ≠ CR.
arrow and intersection
If T and U are test-defined, then so is T ⇒ U, and the intersection of a nonempty set of test-defined sets is test-defined.
not empty, and its ends
SN is test-defined and is the largest member of TT. The smallest member is the set of terms that pass every test; it is strictly above Min, and it has no closed member.
theorem
Let ∀X.A name the intersection over all members of TT, and let assignments take their values in TT. Then Lemma N, the four facts, the soundness theorem and both corollaries hold.

The proof of C2 (consistency) in {{rules}} needs the set that ∀X.X names to have no closed member. For the collections of {{families}} that set is Min; here it is the smallest test-defined set, and the item not empty, and its ends is what makes the proof go through. TT is not closed under union; the lemma after the proof shows it. The item candidates is in Riba’s paper, as a lemma stated for his general setting with a reference to another paper of his for the proof; the proof here was written before that paper was read.

Proof

Candidates. Let P be nonempty and T = P⊥. SN condition: pick a test v⃗ ∈ P; if t ∈ T then t v⃗ ∈ SN, so t ∈ SN by R1 (subterms). Base condition: a member of Base applied to the terms of a test, which are strongly normalizing, is in Base, so in SN by R2 (variable applied). Closure condition: let s →h s′ be safe with s′ ∈ T, and take v⃗ ∈ P; then s v⃗ →h s′ v⃗ is a safe head step with the same argument, because a head step survives more arguments, and s′ v⃗ ∈ SN, so s v⃗ ∈ SN by R3 (safe head step). Closure under steps, which is CR2: if t ∈ T and t → t′, then t v⃗ → t′ v⃗, and t′ v⃗ ∈ SN by R1 (subterms). So T is a type set closed under steps, which is a candidate by the lemma “Candidates are the type sets that are closed under steps” in {{cmpsets}}.

Strictly. TI = Gen({I}) is a candidate, as the example “Three type sets, one from each collection” in {{families}} shows. It does not contain λx.y, by M2 (generated): λx.y has no head step, is not I, and is not in Base. But every test-defined set contains λx.y, by the item passes all of the lemma before the examples.

Arrow and intersection. Let T = P⊥ and U = Q⊥. A term t is in T ⇒ U if and only if t u ∈ U for every u ∈ T, that is, if and only if t u w⃗ ∈ SN for every u ∈ T and every w⃗ ∈ Q. Each list u, w⃗ is a test, because u ∈ SN by the SN condition of T. So T ⇒ U is P′⊥ for the set P′ of those lists, which is nonempty because T contains the variable x and Q is nonempty. For a nonempty set of sets Pi, a term is in the intersection of the Pi⊥ if and only if it passes every test in every Pi; so the intersection is the orthogonal of the union of the Pi, which is nonempty because there is at least one Pi and each is nonempty.

Not empty, and its ends. SN is the first example, and it is the largest member by M1 (largest). The intersection of all members of TT is, by the item arrow and intersection, the orthogonal of the union of all nonempty sets of tests, which is the set of all tests; so it is the set of terms that pass every test. It contains λx.y, which is not in Min, and it has no closed member, both by the lemma before the examples.

Theorem. By the remark in {{rules}} on what the proof asked of the collection that ∀ ranges over: the members are type sets, by candidates; the collection is closed under ⇒ and under nonempty intersections, by arrow and intersection; it is not empty; and the set that ∀X.X names, the smallest member, has no closed member, by not empty, and its ends. ∎

Lemma · Test-defined sets are not closed under unionhere, reviewed

Write K′ for λx.λy.y. Let a = λx. x I δ δ and b = λx. x δ I δ. Let Ta be the set of terms that pass the test a, and Tb the set of terms that pass the test b; each is a test with one term. Then Ta ∪ Tb is not test-defined.

So the union lemma of {{ops}} has no counterpart in TT. The union Ta ∪ Tb is still a type set, and a reducibility candidate, by {{cmpsets}}; it is only not of the form P⊥. Closure under union is the property that Riba’s theorem in {{cmpsets}} is about: the candidates have it, and the sets defined by tests do not. An earlier search by program found no example because it was too small: its terms had at most seven symbols and its tests at most five, counting one for each variable, abstraction and application, and in the example the tests a and b have fifteen each and the term fourteen. The lemma agrees with a remark of Riba’s, that the lattice of biorthogonals is not distributive: a collection of sets that is closed under intersection and under union is distributive. His paper gives no example.

Proof

Three terms are used: p = λx. x K, q = λx. x K′, and t = λx. z (x K) (x K′), where z is a variable. The term t does to its argument what p does and what q does, side by side under z.

p passes a, and q passes b. p a →h a K →h K I δ δ →h (λy.I) δ δ →h I δ →h δ. The arguments of these five head steps are a, K, I, δ and δ, which are normal forms, so the steps are safe; and δ ∈ SN. So p a ∈ SN, by R3 (safe head step) five times. In the same way q b →h b K′ →h K′ δ I δ →h (λy.y) I δ →h I δ →h δ, so q b ∈ SN.

t passes neither. t a → z (a K) (a K′), and a K′ → K′ I δ δ → (λy.y) δ δ → δ δ = Ω. So t a reaches a term that has Ω as a subterm, and t a ∉ SN, by R1 (subterms). Likewise t b → z (b K) (b K′), and b K → K δ I δ → (λy.δ) I δ → δ δ = Ω, so t b ∉ SN.

Every test that p and q both pass, t passes. Let v1,…,vn be a test that p and q pass. If n = 0, there is nothing to show: t is a normal form. Let n ≥ 1. The term p v1…vn is in SN and takes a step to v1 K v2…vn, so v1 K ∈ SN, by R1 (subterms). In the same way v1 K′ ∈ SN, from q. The terms v2,…,vn are in SN because they are terms of a test. So z (v1 K) (v1 K′) v2…vn is in Base, and in SN by R2 (variable applied). The term t v1…vn takes a head step to it, and the step is safe, because its argument v1 is in SN. So t v1…vn ∈ SN, by R3 (safe head step).

The union is not test-defined. Suppose that Ta ∪ Tb = R⊥ for a nonempty set R of tests. Then p and q are members of R⊥, so both pass every test in R. So t passes every test in R, and t ∈ R⊥ = Ta ∪ Tb. But t passes neither a nor b.

The four claims about p a, q b, t a and t b were also checked by a program that searches all runs; so was the fact, not used, that p does not pass b and q does not pass a. ∎

Definition · The smallest test-defined set above a set

For a set S of strongly normalizing terms, S° is the set of the terms that pass every test that every member of S passes.

Write Q for the set of the tests that every member of S passes. It contains the empty test, because S ⊆ SN; so S° = Q⊥ is test-defined, and it contains S. If a test-defined set P⊥ contains S, then every test in P is in Q, so S° ⊆ P⊥. So S° is the smallest test-defined set that contains S.

Example · What replaces the union

Let V be the union of a nonempty set of test-defined sets. Then V° is the smallest test-defined set that contains all of them, and it is the intersection of the test-defined sets that contain them, of which SN is one. For Ta and Tb, the set (Ta ∪ Tb)° contains the term t of the proof of the lemma on unions, which is in neither. So if ∀ ranges over TT, the set ⋃C F(C) that {{more}} gave to existential types is a type set that need not be a member of TT, for instance if F gives Ta at SN and Tb at every other member, and then it is not a value that a variable may take. Existential types in that form are not available over TT.

Quoted from Riba. He reads an existential type as the smallest set of the collection above the union, for candidates and for biorthogonals alike. The rule that introduces a member is then true for every such collection. Of the rule that uses a member he writes that the only collections for which it is known to be true are those closed under unions, and that this closure fails for some systems of rewriting. His remedy keeps that definition of the set and changes the terms: a member is used through a new form of term, let x = t in c, which takes its step only once t has become a value, and the contexts of that form are added to the contexts that serve as tests. The rule for that form of term is true for candidates and for biorthogonals. Here: over TT the set he takes is (⋃C F(C))°.

On this page, with no new form of term, two things stand in for that rule. The lemma “Using a member of the smallest test-defined set above a union” gives a condition under which the fact of {{more}} holds with (⋃C F(C))° in the place of the union. And the encoding of {{more}} is available: it is built from ⋂ and ⇒, so it is test-defined if the sets F(C) are, a member is made by λx.λk. k x and used by applying it, by the proof given there, which uses the union only for the way back. The price is that the term is not unchanged.

e1 = λx. x y δ and e2 = λa.δ.

Di is the set of the terms that pass the test ei, a test of one term, for i = 1 and i = 2.

Bi = Di ⇒ SN.

h = λm. z (m e1) (m e2), with z a variable.

Quoted. The two terms are those of an example in Riba’s paper on the values of reducibility candidates: e1 e1 and e2 e2 are in SN, and e1 e2 reaches δ δ. He uses them, with a term that may step to either of two terms, to show that the rule that uses a member of a union fails there. Here: the term h does the work of that choice.

Lemma · Using a member of the smallest test-defined set above a unionhere, reviewed

For a term s, a variable x and a set U, write W(s, U) for the set of the strongly normalizing terms v with s[v/x] ∈ U.

at the head
Let S be a set of strongly normalizing terms, let U be test-defined, and let u1,…,uk be strongly normalizing terms, with k ≥ 0. If v u1…uk ∈ U for every v ∈ S, then r u1…uk ∈ U for every r ∈ S°.
exactly
Let U be test-defined. The statement “for every nonempty set S of strongly normalizing terms: if s[v/x] ∈ U for every v ∈ S, then s[r/x] ∈ U for every r ∈ S°” is true if and only if W(s, U) is empty or test-defined.
unchanged
B1 and B2 are test-defined, v v ∈ SN for every v ∈ B1 ∪ B2, the term h is in (B1 ∪ B2)°, and h h ∉ SN. So W(x x, SN) is not test-defined.
one use
δ v ∈ SN for every v ∈ B1 ∪ B2, and δ h ∉ SN.
with ∧
For C in TT let G(C) = C ∩ (C ⇒ SN), the set that the type expression X ∧ (X → Y) of {{and}} names if X is sent to C and Y to SN. Then v v ∈ SN for every C and every v ∈ G(C), and h is in (⋃C G(C))°.
the encoding
For a function F from TT to TT write N for (⋃C F(C))° and E for the encoding ⋂D ((⋂C (F(C) ⇒ D)) ⇒ D) of {{more}}, with C and D over TT. For every F, λe. e I ∈ E ⇒ N. For the F that gives B1 at SN and B2 at every other member of TT, λx.λk. k x ∉ N ⇒ E.

The fact that uses a member of an existential type in {{more}} reads: if s[v/x] ∈ U for every member v of the union, then s[r/x] ∈ U for a member r. The lemma says what becomes of it over TT, with the smallest test-defined set above the union in the place of the union and with U test-defined. It holds if s is x applied to strongly normalizing terms in which x is not free. It fails for s = x x and U = SN, and for s = δ x, in which x occurs once, as an argument; so how often the member is used does not decide it. The item exactly says for which s and U it holds if any nonempty set of strongly normalizing terms may stand in the place of the union: exactly if W(s, U) is empty or test-defined. For a union of members of TT that condition is enough; that it is needed is proved for arbitrary sets only.

The item with ∧ shows that the failure is not an accident of a function chosen by hand. The rule that uses a member with the term unchanged concludes Γ ⊢ s[t/x] : B from Γ ⊢ t : ∃X.A and Γ, x:A ⊢ s : B, with X free neither in Γ nor in B. Let ∃X.A name the smallest test-defined set above the union, and take Γ = w : ∃X.(X ∧ (X → Y)), t = w, s = x x and B = Y. Both judgments above the line are true, and the one below, w : ∃X.(X ∧ (X → Y)) ⊨ w w : Y, is false: send Y to SN and replace w by h. So with ∧ among the rules that rule is false. For System F with ∃ and without ∧ only the fact about sets is refuted here; no type expression was found that names a function for which it fails.

By the item the encoding, the two terms of {{more}} go one way only between the encoding and the smallest test-defined set above the union. For one function F a term that ignores its argument can go the other way: λx.λk. k (λm.I) does it for the F of that item, because λm.I ∈ B1. Whether one closed term, the same for every F, does it is open for the terms of this page. Quoted from Riba: in his calculus with let there is such a term, λy.λx.(let x = y in x z) in his notation, and his term for the other way is λx. x (λy.y), the λe. e I of this page.

Quoted from Pitts’s paper on parametric polymorphism and operational equivalence. The item at the head is, in the words of this page, the argument by which he proves the rule that uses a member of a list type, in a language where the use is a form of term that waits for a value: the use, followed by a test of the result, is one test of the member, so it has to be checked on the members of the union only. For existential types he writes that the like holds and omits the details. Worked out for this page, in outline, and not reviewed. The term h is an abstraction, so let x = h in x x takes its step and reaches h h, while every member of B1 ∪ B2 passes that test; so his smallest set above the union does not contain h. Proof

At the head. Let U = R⊥ and take w⃗ ∈ R. The list u1,…,uk, w⃗ is a test, because its terms are strongly normalizing. Every v ∈ S passes it: v u1…uk ∈ U, so v u1…uk w⃗ ∈ SN. So r passes it, by the definition of S°. This holds for every w⃗ ∈ R, so r u1…uk ∈ R⊥.

Exactly. Write W for W(s, U). Let W be test-defined, and let S be as in the statement, with s[v/x] ∈ U for every v ∈ S. Then S ⊆ W, so S° ⊆ W, because S° is the smallest test-defined set that contains S; that is the claim. If W is empty, no nonempty S satisfies the hypothesis. In the other direction, let W be nonempty and let the statement hold; take S = W. Every r ∈ W° has s[r/x] ∈ U, and r ∈ SN because it passes the empty test; so W° ⊆ W. And W ⊆ W°. So W = W° is test-defined.

Unchanged. e1 and e2 are normal forms, so each is a test of one term; Di is test-defined, and Bi is test-defined by the item arrow and intersection of the lemma “Test-defined sets form a fourth collection”.

Every v ∈ Bi is in Di and has v v ∈ SN. First, ei ∈ Di: e1 e1 takes two head steps, to e1 y δ and to y y δ δ, a member of Base; their arguments e1 and y are normal forms, so e1 e1 ∈ SN by R3 (safe head step), twice. And e2 e2 takes a safe head step to the normal form δ, so e2 e2 ∈ SN by R3 (safe head step). Now let v ∈ Bi. Then v ei ∈ SN, because ei ∈ Di; that says v ∈ Di; so v v ∈ SN, because v ∈ Di ⇒ SN.

h is in (B1 ∪ B2)°. Let v1,…,vn be a test that every member of B1 ∪ B2 passes. If n = 0, h passes it: h is a normal form. Let n ≥ 1. The term gi = λm. m ei is in Bi: for d ∈ Di, the term d is in SN, as a subterm of d ei, so gi d takes a safe head step to d ei ∈ SN, and gi d ∈ SN by R3 (safe head step). So gi passes the test, and gi v1…vn takes a step to v1 ei v2…vn, so v1 ei ∈ SN by R1 (subterms), for i = 1 and i = 2. Now h v1…vn takes a head step to z (v1 e1) (v1 e2) v2…vn, which is in Base; the step is safe because v1 is a term of a test; so h v1…vn ∈ SN by R3 (safe head step).

h h ∉ SN. h h → z (h e1) (h e2), and h e1 → z (e1 e1) (e1 e2), and e1 e2 → e2 y δ → δ δ = Ω. So h h reaches a term that contains Ω, and h h ∉ SN by R1 (subterms). And W(x x, SN) contains B1 ∪ B2; if it were test-defined it would contain (B1 ∪ B2)°, and so h.

One use. For v ∈ B1 ∪ B2, δ v takes a safe head step to v v ∈ SN, so δ v ∈ SN by R3 (safe head step). And δ h → h h, so δ h ∉ SN, by R1 (subterms).

With ∧. If v ∈ G(C), then v ∈ C and v ∈ C ⇒ SN, so v v ∈ SN. By the proof of the item unchanged, Bi ⊆ Di, so G(Di) = Di ∩ Bi = Bi, and B1 ∪ B2 ⊆ ⋃C G(C). A test that every member of the larger set passes is passed by every member of the smaller, so (B1 ∪ B2)° ⊆ (⋃C G(C))°, and h is in it.

The encoding. N is in TT, so a member d of E can be instantiated at D = N. For v ∈ F(C), I v takes a safe head step to v ∈ N, so I ∈ F(C) ⇒ N for every C, by the closure condition, and d I ∈ N; the closure condition again gives (λe. e I) d ∈ N. Now let F give B1 at SN and B2 at every other member, so that ⋃C F(C) = B1 ∪ B2 and h ∈ N. δ ∈ Bi ⇒ SN for both i, by the item one use, so δ ∈ ⋂C (F(C) ⇒ SN). And (λx.λk. k x) h δ reaches δ h, which is not in SN. So (λx.λk. k x) h is not in (⋂C (F(C) ⇒ SN)) ⇒ SN, which is one of the sets that E is the intersection of. The term that ignores its argument: (λm.I) d takes a safe head step to I for every d ∈ D1, so λm.I ∈ B1; then for k ∈ ⋂C (F(C) ⇒ D) and u ∈ SN, (λx.λk. k (λm.I)) u k reaches k (λm.I) ∈ D by two safe head steps. ∎

Lemma · The lemma on unions with closed terms, and no closed term that mergeshere, reviewed

Let a, b, Ta, Tb, p and q be as in the lemma on unions and its proof, where p = λx. x K and q = λx. x K′.

closed witness
The closed normal form t′ = λx.λf. f (x K) (x K′) is in neither Ta nor Tb, and it is in (Ta ∪ Tb)°, the smallest test-defined set that contains Ta ∪ Tb.
no merging
There is no closed term f such that f t s ∈ T ∩ U for all test-defined sets T and U, all t ∈ T and all s ∈ U.

The first item answers the search by program that the lemma on unions reports: closed examples exist; this one has fifteen symbols, eight more than the search tried. The second is the same failure seen from the side of the terms: the union of two test-defined sets would be test-defined if two tests could be joined into tests that are passed exactly if one of the two is; a term that merges would do the dual, joining two members into one that passes what either passes. Quoted from Matthews’s guide. The guide has a term of the second sort for Krivine’s realizability, which it says “satisfies the instruction fork”: applied to two terms, it passes every stack that one of the two passes. That condition is about all terms. With strong normalization as what passing means, a term outside SN refutes it at once, which is why the item here asks t ∈ T and s ∈ U; for terms in SN the two forms agree. Such a term exists if the model has only two truth values in a certain sense, and then, for a countable structure, a single term proves every formula that has a proof; the guide reports the proof from slides of Krivine’s. The model is then a model by forcing, and of the realizability models that come from forcing the guide says that such a model “loses its computation content”. Both items were found by a reader of the guide for this page and checked by the writer.

Proof

Closed witness. t′ a → λf. f (a K) (a K′), and a K′ reaches Ω, as in the lemma on unions, so t′ a ∉ SN. Likewise t′ b ∉ SN, because b K reaches Ω. Now let v1,…,vn be a test that every member of Ta ∪ Tb passes. If n = 0, there is nothing to show. Let n ≥ 1. The members p and q pass it, so v1 K and v1 K′ are in SN, as in the lemma on unions. Remark · What tests are for

Nothing in the main line needs TT; it is a smaller collection than the candidates, and it loses Min and the union lemma. What it has that the other three collections lack is that a set is given by what is done to its members, and “what is done” can be richer than applying arguments. That a set is given by what is done to its members is the sense in which {{cmpsem}} says that tests grow from Tait’s side: the condition that P⊥ has whatever the test for passing is, as long as passing survives undoing a safe head step, is the closure condition, which is the condition {{typeset}} chose. On this page P⊥ is closed under steps as well, because SN is; in Krivine’s realizability it is not, as the remark “The same construction in Krivine’s realizability” says.

{{classical}} is where the sets given by tests do something that the collection of all type sets cannot: for the terms of Parigot’s λμ-calculus a name stands for a test, the rule that makes a μ-abstraction is false over all type sets, and it is true over the sets defined by tests. Being test-defined is more than that rule needs: {{classical}} names a condition that is enough, and gives a type set that has it and is not test-defined. For Krivine’s realizability the same construction was checked against Matthews’s guide, and the remark “The same construction in Krivine’s realizability” reports it.

Quoted from Pitts’s paper on parametric polymorphism and operational equivalence. For pairs of terms, in a language with typed terms, lists and recursion without a bound, so that a term may run forever, the construction is his. A test is a stack of the forms of the language that wait for a value. What is observed is a closed term whose type expression is one of lists: a pair of terms passes a pair of tests if both such terms evaluate to the empty list or neither does. A relation between terms is test-defined, in his word ⊤⊤-closed, if it is the set of the pairs that pass every pair of tests of some set. His relations for lists and for existential types are the smallest test-defined relations above a union of pairs of values; for lists the union mentions the relation that is being defined, and a greatest fixed point is taken. Over test-defined relations he proves that two terms are related at their type expression exactly if they are equal in every context: his Theorem 4.15, which he states for the largest relation that respects the forms of terms, substitution and evaluation to the empty list, and of which he says that it is equality in every context. He writes that the construction arose “as a way of dealing with dynamic allocation of local state” in a paper of his and Stark’s, which was not read for this page.

Remark · The same construction in Krivine’s realizability

Quoted from Matthews’s guide. Krivine’s realizability is a semantics for classical logic and for set theory. A formula names a set of terms, as a type expression does here, and the set is given by tests. A test there is a stack: a list of closed terms with a marker at its end. A closed term together with a stack is a process, and the process evaluates by head steps only, with two more instructions: one captures the stack that the term is running against, and one puts a captured stack back. A term passes a test if the process is in a chosen set of processes, the pole. One condition is asked of a pole: if a process evaluates to a member of the pole, then it is a member. A formula is given a set of stacks, and it names the terms that pass every one of them. The set of stacks of “for all” is the union of the sets of stacks of the instances, which is the item arrow and intersection for intersections. The set of stacks of an implication is defined to be the lists u, w⃗ that the same item computes, and what is then proved is one inclusion: a term that passes them sends every member of the first set into the second.

Four differences, each of which this page can name. The closure condition is stated there once, for the pole, and every set of the form P⊥ inherits it, as the item candidates shows here; closure under steps, CR2, is not inherited there, because a pole need not be closed under evaluation. So in that generality the sets have the closure condition of {{typeset}} and not CR2, and they are neither saturated sets nor candidates, because nothing bounds them by SN. Nothing is asked about normalization, strong or weak: the pole is a parameter, the empty set of stacks is allowed, so that a formula may name the set of all terms, and one axiom of set theory, the one that allows proofs by induction on sets, is proved there by a term that rebuilds itself as it runs and is not in SN. So what that semantics proves is consistency, and not normalization, as Stump’s semantics in {{equality}} does. Terms are closed and only head steps are taken, as in Harper’s note; of the three demands that {{lookback}} lists, the first two are not made, and the place of the third is taken by a quantifier over the individuals of the model, which are sets of pairs of a name and a stack. And a negation has a witness, which the note on complements in {{families}} said no term of this page can be: if a stack is one of the tests of a formula, then the term that puts this stack back sends every member of the set that the formula names to a process in the pole, and that makes it a proof that the formula implies any other.

Worked out for this page, and not reviewed. Three points where the two meet. First, the pole of this section is the set of pairs of a term t and a test v⃗ with t v⃗ ∈ SN. If a test could be a list of arbitrary terms, this set would not satisfy the condition on a pole: (λx.y) Ω takes a head step to y, which is in SN, and is not in SN itself. So the clause that the terms of a test are strongly normalizing is the word “safe” of {{head}}, moved from the step to the test. Second, on this page the set of terms that pass the tests u, w⃗ and the arrow of the two sets are one set, by the item arrow and intersection, where the guide has one inclusion; because a term applied to u and tested with w⃗ is the same term as the term tested with u, w⃗; there the two are different processes, and a pole is closed in one direction only. Third, that setting calls the whole structure, terms, stacks, evaluation and pole, coherent if every term that contains no captured stack fails some test, and coherence is exactly what makes the semantics consistent. The item closed terms fail says that the pole of this section is coherent, with “closed” in the place of “contains no captured stack”; and the term λx.y of the item passes all has its counterpart there if the pole is not empty, a term with a captured stack that passes every test. There coherence is a hypothesis, proved for one pole at a time.
