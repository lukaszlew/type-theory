There are still no type expressions and no typing rules. There are sets of terms, and four facts about them.

Lemma · Four factstextbook

Let T, U and D be type sets, and let F give a type set F(C) for each type set C.

apply
If t ∈ T ⇒ U and u ∈ T, then t u ∈ U.
abstract
If t[u/x] ∈ U for every u ∈ T, then λx.t ∈ T ⇒ U. This is W3 (abstraction).
generalize
If t ∈ F(C) for every type set C, then t ∈ ⋂C F(C).
instantiate
If t ∈ ⋂C F(C) and D is a type set, then t ∈ F(D).

Generalize and instantiate hold in the same words for an intersection indexed by any nonempty set I, with “every i ∈ I” in the place of “every type set C”: if t ∈ F(i) for every i ∈ I, then t ∈ ⋂i∈I F(i); and if t ∈ ⋂i∈I F(i) and j ∈ I, then t ∈ F(j). Both are the definition of the intersection read in the two directions.

Proof

Apply, generalize and instantiate are the definitions of ⇒ and ⋂, read in the other direction.

Abstract. Take u ∈ T. It is in SN by the SN condition, so (λx.t) u →h t[u/x] is a safe head step. Since t[u/x] ∈ U, the closure condition gives (λx.t) u ∈ U. ∎

Three of the four are definitions read backwards. Only abstract uses the conditions, and it uses the SN condition and the closure condition once each. The work was done in {{typeset}} and {{ops}}, in making sure that ⇒ and ⋂ never leave the collection of type sets.

Example · The four facts at work

Claim: λf.λx.f (f x) is in ⋂C ((C ⇒ C) ⇒ (C ⇒ C)). The term applies its first argument twice.

  1. Fix any type set C. Take g ∈ C ⇒ C and u ∈ C.
  2. Apply: g u ∈ C. Apply again: g (g u) ∈ C.
  3. Abstract over x: λx.g (g x) ∈ C ⇒ C.
  4. Abstract over f: λf.λx.f (f x) ∈ (C ⇒ C) ⇒ (C ⇒ C).
  5. Generalize: C was arbitrary, so the term is in the intersection.

Nothing here looked inside C. It could be SN, TK, or a type set nobody has described.

Example · Self-application

Recall that ID = ⋂C (C ⇒ C). Claim: δ ∈ ID ⇒ ID.

  1. Take any u ∈ ID.
  2. Instantiate with D = ID: u ∈ ID ⇒ ID.
  3. Apply: u u ∈ ID.
  4. Abstract: λx.x x ∈ ID ⇒ ID.

Since I ∈ ID, apply gives δ I ∈ ID, so δ I ∈ SN. The instantiate line uses ID at itself. That is allowed because ID was defined by intersecting over all type sets, and ID is one of them.

The sets also discriminate: δ ∉ ID. Otherwise apply would give δ δ = Ω ∈ ID.
