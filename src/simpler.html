Could the definition be simpler? The measure is the list of requirements W1 to W5 at the end of {{obstacle}}.

W1 (inside SN) is the SN condition. The Base condition and the closure condition are what W2 (arrow), W3 (abstraction) and W5 (variables) force, as narrow points 2, 3 and 4 show. W4 (intersection) is used in narrow point 2 and proved in {{ops}}.

The narrow points show that the conditions cannot be weakened in the ways tried. They do not show that this list of conditions is the only one that works. {{cmpsets}} gives another.

Each narrow point puts a simpler definition of a type set on trial. A set qualifies if it satisfies the definition on trial. The trial fails if some requirement fails for the sets that qualify.

Narrow point 2 · Less than the Base condition

Goal
A definition under which every member of a type set is strongly normalizing (W1), the arrow of two type sets is a type set (W2), an intersection of type sets is a type set (W4), and every type set contains every variable (W5).
Try
Keep the SN condition, leave the closure condition aside, and ask for less than the Base condition. Four ways are tried in turn. Each one repairs the one before it. W5 (variables) alone would rule out the first two. They are tried without it, because they show that W2 and W4 already force every type set to have members, and all type sets to share some.
Breaks
  1. Ask nothing more. The empty set qualifies, and so does SN. But ∅ ⇒ SN is the set of all terms, because “for every u ∈ ∅” asks nothing. It contains Ω, which is not in SN. So ∅ ⇒ SN fails the SN condition and does not qualify, and W2 (arrow) fails. A type set has to have a member.
  2. Ask only that the set is not empty. Then {I} and {K} qualify. Their intersection is empty and does not qualify, so W4 (intersection) fails. All type sets have to have members in common. W5 (variables) says which: at least the variables.
  3. Ask only for the variables. The set Var of all variables qualifies. But Var ⇒ Var is empty, because t x is an application and never a variable. So Var ⇒ Var does not contain the variables and does not qualify, and W2 (arrow) fails.
  4. Ask only for the members of Base with n ≤ 1. That is a variable alone or applied to one argument. Let U be exactly the set on trial: the variables and the terms x u with u ∈ SN. Then U qualifies, and so does SN. No term x u v is in U. So SN ⇒ U contains the variables and no term x u: it is exactly Var, the set of the third trial. It does not qualify, and W2 (arrow) fails. One arrow further, SN ⇒ (SN ⇒ U) contains no variable at all. Each arrow uses up one argument.
Adding the closure condition does not rescue any of the four. The empty set satisfies it. Closing {I} and {K} gives cl({I}) and cl({K}), which are still disjoint, because a term has at most one head step. Closing Var or U adds only abstractions applied to arguments, so the same terms are still missing.
Hence
  1. A variable in T serves as the argument: if x ∈ T and t ∈ T ⇒ U, then t x ∈ U, so t x ∈ SN, so t ∈ SN by R1 (subterms). This gives W1 (inside SN) for T ⇒ U.
  2. W2 (arrow) says that T ⇒ U is a type set, and W5 (variables) says that a type set contains the variables. So T ⇒ U must contain the variables. This follows from W2 and W5 and is no new requirement. It needs x u ∈ U for every u ∈ T. SN qualified in every trial, so T may be SN, and then all we know about u is that it is in SN.
  3. Each arrow adds one argument to what is asked: one arrow deeper it reads x u1 u2 ∈ U. Arrows nest to any depth. So the condition that keeps itself true under ⇒ is the Base condition, for every n.
  4. The Base condition puts the same set, Base, inside every type set. So an intersection of type sets is never empty, which W4 (intersection) needs.

Narrow point 3 · Undoing a step

Goal
W3 (abstraction): if t[u/x] ∈ U for every u ∈ T, then λx.t ∈ T ⇒ U. By the definition of ⇒, the claim λx.t ∈ T ⇒ U means (λx.t) u ∈ U for every u ∈ T. W3 hands us only t[u/x] ∈ U, and t[u/x] is what (λx.t) u becomes after one step. So if every type set that contains the term after that step also contains the term before it, then W3 holds.
Try
Replace the closure condition by the simplest condition that does this: every type set is closed under undoing a step, any step.
Breaks
Twice. First, a step may throw its argument away. The variable y is in every type set, and (λx.y) Ω steps to y, but it is not in SN, because Ω is still inside it. So ask at least that the argument is in SN. Second, even then a step inside an abstraction can hide a loop. (λz.y) δ is in every type set, since a head step with a strongly normalizing argument takes it to y. Undoing a step inside it gives (λz.(λx.y) (z z)) δ, and the argument z z is in SN. But this term also steps to (λx.y) (δ δ), which is not in SN. Either way a term that is not in SN would be in every type set, so W1 (inside SN) fails.
Hence
The closure condition undoes only a head step, and only if the head step is safe. R3 (safe head step) says that SN is closed in exactly this way, so at least one type set exists. W3 (abstraction) still follows: the step from (λx.t) u to t[u/x] is a head step, and it is safe because u comes from a type set.

Narrow point 4 · Trailing arguments

Goal
W2 (arrow) again: the arrow of two type sets has to be a type set. The closure condition is now one of the conditions, so T ⇒ U has to satisfy it too.
Try
State the closure condition for the bare form only: if t[u/x] ∈ T and u ∈ SN, then (λx.t) u ∈ T.
Breaks
W2 (arrow) fails. Let U be the smallest set with the Base condition and this short rule. It qualifies. Its members have two forms: x u1…un, or an abstraction applied to exactly one argument. Then I ∈ U ⇒ U, and the short rule for U ⇒ U asks for (λz.I) y ∈ U ⇒ U, which means (λz.I) y v ∈ U for v ∈ U. That term has neither form, so it is not in U. So U ⇒ U does not satisfy the short rule and does not qualify.
Hence
Membership in T ⇒ U is tested by adding one argument. So a head step allows arguments after the redex, as in (λx.t) u u1…un, and it survives one more argument. Then the closure condition passes through ⇒ in one line.
