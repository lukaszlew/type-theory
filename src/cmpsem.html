These are further ways of giving System F a meaning. They differ in what a type expression stands for, in what the meaning is used for, and in which of the two definitions of {{cmpsets}}, Tait’s saturated sets or Girard’s candidates, they grow from. The table is from general knowledge of the literature, except where a source is named, and was not checked against sources for this page.

Not treated: semantics in which a type expression names an ordered set of pieces of information, such as domains and Girard’s coherence spaces, which model programs that run forever and are not about normalization at all. Within this page, Mitchell’s generalization in {{good}} and the proofs by union in {{more}} grow from Tait’s side, because unions and the one-line closure proofs are what saturated sets are good at.

One set is missing from the list: the set of terms that the rules give the type expression A. It looks like the natural set for A to name, and it cannot serve here. It presupposes the rules, so it cannot be used to show that the rules are sound. It is also not a type set: the Base condition asks for x u with every strongly normalizing u, and some of those are not typable, as quoted in {{true}}. By the theorem this set is inside ⟦A⟧, and by the lemma “True and not derivable” it can be strictly inside.
