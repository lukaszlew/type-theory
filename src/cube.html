System F is one corner of a cube of eight systems, described by Barendregt. The starting corner is the simply typed λ-calculus, whose type expressions are built from arrows alone. Three features can be added to it independently. Each lets one sort of thing depend on another.

The definition of a type set in {{typeset}} serves all eight corners. What changes from corner to corner is which type sets get names.

  • Without polymorphism there is no ⋂ and no impredicative definition. The set for each type expression can be defined by recursion on the type expression, narrow point 5 does not arise, narrow point 6 shrinks to one lemma proved by recursion on the type expression, and what is left is Tait’s proof of 1967.
  • Type operators cost what {{kinds}} and {{fomega}} show. Kinds are plain sets, with no conditions to check.
  • Dependent types. Πx:A.B names a dependent arrow, which is a type set by the proof of the arrow lemma. There is one new obligation. A type expression can now contain a term, and if that term takes a step, then the type expression must still name the same set, because the rule of term conversion says so. That is why a family is asked to be constant along steps. {{dep}} carries this out.

So in this semantics the three features cost about the same, and they do not interfere. Each adds names, and none changes the collection of type sets. This is a statement about the setting of this page, where terms carry no annotations. The usual presentations of the dependent corners annotate terms with type expressions, which in turn contain terms. Showing that every term is strongly normalizing, annotations included, takes more bookkeeping than {{dep}} does: the erasure lemma of {{erasure}} says exactly what is missing. One known route, due to Geuvers and Nederhof, maps the Calculus of Constructions into Fω. That is quoted and not checked here.

Where type operators and dependent types meet. The families of {{fam}} form one more kind. Write term → ∗ for it, and term → κ for the functions from terms to the members of κ that are constant along steps. A family variable is then a variable of the kind term → ∗. The type expression λx.B names the family w ↦ ⟦B⟧ρ[x↦w], and A[P:=x.B] is the ordinary substitution of λx.B for P, followed by steps inside the type expression. With polymorphism, functions on type sets and dependent types together, this is the last corner of the λ-cube, the Calculus of Constructions, in the form without annotations that this page uses. This paragraph is a sketch: the clauses and rules for the kinds term → κ are not written out.

How strong a proof has to be. {{strength}} treats System F. The same pattern shows across the systems. The rows are quoted from the literature.

SystemWhat a proof of strong normalization needs
Simply typed λ-calculus, with no ∀First-order arithmetic is enough.
System FMore than second-order arithmetic. Third-order arithmetic is enough.
System FωMore than arithmetic of any finite order.
System U⁻No proof exists. Some typable term is not in SN, as narrow point 7 reports.

Past the cube. The Calculus of Inductive Constructions, the theory behind proof assistants such as Coq and Lean, adds two things to the last corner. Universes are a tower of levels, like the levels of kinds in {{allkinds}}, and each level needs a set that is closed under everything below it. Inductive types add new forms of terms, so limit 4 (new forms of terms) in {{limits}} applies and {{typeset}} has to be redone. Both are much harder than anything here, and this page does not attempt them.
