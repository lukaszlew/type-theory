Type expressions can now contain terms. This section adds three forms of type expression, extends Lemma N and the addition lemma of {{price}} to terms inside type expressions, extends the definition of a true judgment, and adds five rules.

Definition · Type expressions that contain terms

A family variable P is a third sort of variable.

There are three more forms of type expression: P t, a family variable applied to a term; Πx:A.B, where the term variable x may be free in B; and ∀P.A.

On this page a family variable takes one term, and a type expression is never abstracted over a term. The price is paid in {{cube}}: the kinds of functions from terms, which the dependent corners of the λ-cube need in full, are only sketched there.

An assignment ρ now also gives a family ρ(P) for each family variable P and a term ρ(x) for each term variable x.

t[ρ] is t with each free variable x replaced by ρ(x), all at once.

u ≡ v is short for the type expression ∀P. P u → P v.

Three clauses are added:

⟦P t⟧ρ = ρ(P) at the term t[ρ]
⟦Πx:A.B⟧ρ = Πu∈⟦A⟧ρ ⟦B⟧ρ[x↦u]
⟦∀P.A⟧ρ = ⋂V ⟦A⟧ρ[P↦V]

A → B is now the case of Πx:A.B in which x is not free in B.

Example · A type expression for equality

The type expression u ≡ v names EQ(u[ρ], v[ρ]) of {{darrow}}. The closed type expression I I ≡ I names EQ(I I, I), which contains I. The type expression Πx:X. x ≡ x names the terms that send every u ∈ ρ(X) into EQ(u, u), and λx.I is one of them.

Lemma N · Extended to terms inside type expressionshere, reviewed

N1
Type set. ⟦A⟧ρ is a type set.
N2
Substitution. ⟦B[u/x]⟧ρ = ⟦B⟧ρ[x↦u[ρ]]. Also ⟦A[P:=x.B]⟧ρ = ⟦A⟧ρ[P↦V]. Here A[P:=x.B] is A with every P t replaced by B[t/x], and V is the family w ↦ ⟦B⟧ρ[x↦w].
N4
Term steps. Running a term does not change what a type expression names. If a term inside A takes a step and the result is A′, then ⟦A⟧ρ = ⟦A′⟧ρ. If the term ρ(x) takes a step and the result is ρ′, then ⟦A⟧ρ = ⟦A⟧ρ′.
Proof

N0 (free variables) holds as stated, for all three sorts of variable.

N4 comes first, by induction on A. The case that matters is P t. A step of a term inside t, or of ρ(x), takes t[ρ] to the new term in zero or more steps, and ρ(P) is constant along steps, because it is a family. In every other case what the type expression names is computed from what the type expressions inside it name.

N1. By induction on A. P t names a value of a family. For Πx:A.B, the function u ↦ ⟦B⟧ρ[x↦u] gives type sets by induction, and the lemma on the dependent arrow in {{darrow}} asks nothing more of it. ∀P.A is an intersection over all families, which is a type set by {{fam}}.

N2. By induction, unfolding the clauses. In the equation for A[P:=x.B] the case P t reads ⟦B[t/x]⟧ρ = ⟦B⟧ρ[x↦t[ρ]] = V(t[ρ]), by the equation for B[u/x]. That V is a family, and not only a function from terms to type sets, is N4 (term steps). ∎

Addition lemma · Extended to parts that are termshere, reviewed

A part of an addition may now be a term t, which contributes the term t[ρ] to the clause, or a type expression B under a bound term variable x, which contributes the function w ↦ ⟦B⟧ρ[x↦w]. The addition lemma of {{price}} holds with one more hypothesis under names: the operation of the clause gives a type set for all inputs that are type sets, families and terms, and it is constant along steps of its term inputs. Then Lemma N holds with N4 (term steps) for the language with the new form.

Proof

As in {{price}}, with one more case in the induction for N4 (term steps). A step of a term inside the new form, or of ρ(x), changes a term input of the operation by zero or more steps, which the operation does not see, by the new hypothesis; and it changes no other input, by the induction. The function w ↦ ⟦B⟧ρ[x↦w] is a family by N4 (term steps), so it is an input of the kind the hypothesis speaks of. For N2 (substitution) at a term part, the case uses that substituting a term and then applying ρ is the same as applying ρ with the substituted term: t[u/x][ρ] = t[ρ[x↦u[ρ]]], a fact about substitution and not about type expressions. The part rules is unchanged, with the definition of a true judgment of this section in the place of that of {{judg}}; the five rules of {{rules}} stay true under it by their old proofs, the two rules for → being the cases of “Π in” and “Π out”. ∎

Definition · True judgment, with terms inside type expressions

A context may now be dependent: Ai may contain the earlier variables x1,…,xi−1, and A may contain all of them.

The judgment is true, written Γ ⊨ t : A, if the following holds: for every ρ such that ρ(xi) ∈ ⟦Ai⟧ρ for each i, and ρ(y) = y for every term variable y that is not in Γ, the term t[ρ] is in ⟦A⟧ρ.

If no type expression contains a term variable, then this is the definition of {{judg}}, with ui = ρ(xi). The clause ρ(y) = y says that a term variable outside Γ stands for itself. It is there so that a judgment speaks only about the variables that Γ declares, even when a type expression in Γ mentions another one, and so that C1 (strong normalization) can replace every variable by itself exactly as in {{rules}}.

Theorem · The rules for dependent typeshere, reviewed

The theorem and both corollaries hold with the five rules of the table added. The two rules for → are the cases of “Π in” and “Π out” in which x is not free in B.

RuleFromConclude
Π inΓ, x:A ⊢ t : BΓ ⊢ λx.t : Πx:A.B
Π outΓ ⊢ t : Πx:A.B and Γ ⊢ u : AΓ ⊢ t u : B[u/x]
∀ in, for familiesΓ ⊢ t : A, with P not free in ΓΓ ⊢ t : ∀P.A
∀ out, for familiesΓ ⊢ t : ∀P.AΓ ⊢ t : A[P:=x.B]
term conversionΓ ⊢ t : A, and A, B joined by steps of the terms inside themΓ ⊢ t : B
Proof

Lemma N is proved. So, by the part rules of the addition lemma, it is enough that each rule is true. Π in is abstract for the dependent arrow. Π out is apply, and then N2 (substitution) turns ⟦B⟧ρ[x↦u[ρ]] into ⟦B[u/x]⟧ρ. The two ∀ rules are generalize and instantiate over families, and instantiate is used at the family of N2 (substitution). Term conversion is N4 (term steps).

The corollaries are proved as they are for System F. Each variable is replaced by itself, which is allowed because each ⟦Ai⟧ρ is a type set and so contains xi. ∎

Example · Why term conversion needs a family

{{fam}} gave a function V that is not a family: V(u) is SN if u is the term I itself, and Min otherwise. If it counted as a family, the rule of term conversion would be false. That rule leads from z : P I ⊢ z : P I to z : P I ⊢ z : P (I I). With V for P and I for z: I ∈ V(I), and I ∉ V(I I).

Remark · What this treatment of dependent types covers

Where “constant along steps” is used. Two of the five rules of this section need families to be constant along all steps: term conversion, which is N4 (term steps) itself, and “∀ out, for families”, because the function w ↦ ⟦B⟧ρ[x↦w] that it instantiates at has to be a family, and the proof of N4 (term steps) makes it one only because every ρ(P) is constant along all steps. If families were asked less, that function could fail to be one: with B = P (y x), a safe head step of w is not a head step of y w. The dependent arrow needs nothing of its function, by {{darrow}}. {{fam}} lists what every construction on this page asks.

What is proved. Strong normalization for terms that carry no annotations, which is the price of Curry style named in {{rules}}. The usual presentations of dependent types put type expressions inside terms, and those type expressions contain terms again. Showing that everything there is strongly normalizing, annotations included, takes more bookkeeping, and this page does not do it. {{cube}} comes back to this.
