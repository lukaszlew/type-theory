System Fω has type expressions that name functions on type sets, such as λX:∗. X → X. Its semantics needs one more notion, and it is a light one.

Definition · Kind

Write Ty for the collection of all type sets of {{typeset}}.

The kinds are these sets:

∗
the set Ty itself;
κ → κ′
the set of all functions from the kind κ to the kind κ′.

Every kind is a nonempty set. For a kind κ and a function H from κ to Ty, ⋂c∈κ H(c) is the intersection indexed by κ, in the sense of {{ops}}: the terms that are in H(c) for every c ∈ κ.

This is a modeling choice: a kind is a plain set, with nothing like the three conditions of {{typeset}}. Those conditions exist because terms are run. The members of kinds are sets and functions on sets, and nothing at this level is run. The price is paid in the metatheory, and {{fomega}} names it. {{allkinds}} gives the other reading of kinds, as sets of type expressions with the three conditions, and says which question each reading answers.

Example · Members of the kind ∗ → ∗

Every function from type sets to type sets is a member, however it is given:

  • C ↦ C ⇒ (TK ⇒ C), which uses a hand-built type set as a fixed ingredient;
  • C ↦ C ⇒ C, and the constant function C ↦ SN;
  • the function that gives SN if I ∈ C and Min otherwise.

The page has used members of this kind since the definition of ⋂C F(C), where F was any function from type sets to type sets. As with type sets, there are far more members than type expressions to name them.

One kind further up, the function F ↦ ⋂C F(C) is a member of (∗ → ∗) → ∗. So intersection over all type sets is itself a member of a kind.

Example · An intersection over a kind

⋂F∈∗→∗ ⋂C (F(C) ⇒ F(C)) is a type set. It contains I, because I ∈ T ⇒ T for every type set T, and each F(C) is a type set. The function that gives SN if I ∈ C and Min otherwise is one of the F it is tested against.

No new lemma is needed. ⋂c∈κ H(c) is an intersection indexed by a nonempty set, so it is a type set by the intersection lemma of {{ops}}, and generalize and instantiate of {{facts}} hold for it.
