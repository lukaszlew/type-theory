The natural numbers have appeared three times: as the Church numerals cNat with induction in {{implicit}}, as the least fixed point of {{more}} whose members carry their predecessor, and as the Nat of {{self}}, which is the Church numerals again under a self type. This section puts the ways of building an inductive type side by side, adds a third in its general form, which is Mendler’s, and says what each costs in this semantics. The general form was chosen because Cedille uses it with good results, and the question was whether those results survive the move from Cedille’s rules to sets.

The Mendler-style fixed point

Definition · Mendler algebra, and the fixed point

Let F be any function from type sets to type sets. For a type set D, the Mendler algebras into D are

Alg(F, D) = ⋂C ((C ⇒ D) ⇒ (F(C) ⇒ D))

with C over all type sets, and the Mendler fixed point of F is

Fix(F) = ⋂D (Alg(F, D) ⇒ D)

The constructor is the term in = λu.λa. a (λr. r a) u.

A member of Alg(F, D) is one layer of a recursion: given a way c to handle a smaller thing of any type set C, it handles a thing of F(C). A member of Fix(F) runs any such layer. The name is Mendler’s, and the form is the one Firsov, Blair and Stump use in Cedille. It is older than that: Matthes’s thesis has this encoding, with no condition on the signature, and its constructor, as the translation of his variant of Mendler’s system without recursion into his system eF, an extension of System F that he embeds in System F; with the annotations erased, his constructor is the term that in u reaches by one head step. Nothing is asked of F: not that it is monotone, and not that Fix(F) is a fixed point of it in any sense. The name “fixed point” is kept because it is the usual one.

Lemma · The Mendler fixed point, for any Fhere, reviewed

Let F be any function from type sets to type sets.

type set
Fix(F) is a type set, and so is Alg(F, D) for every type set D.
in
in ∈ F(Fix(F)) ⇒ Fix(F).
fold
If a ∈ Alg(F, D), then λz. z a ∈ Fix(F) ⇒ D, and (λz. z a) (in y) reaches a (λr. r a) y by three head steps: the layer a is run on y, with λr. r a as the way to handle a smaller thing.
Proof

Type set. Both are built from type sets by ⇒, by F, and by intersections indexed by the collection of all type sets. The arrow lemma and the intersection lemma of {{ops}} apply.

in. Take u ∈ F(Fix(F)). It is to be shown that in u ∈ Fix(F): that for every type set D and every a ∈ Alg(F, D), in u a ∈ D. The term in u a reaches a (λr. r a) u by two head steps, both safe, because u and a are in SN. Instantiate a at C = Fix(F): a ∈ (Fix(F) ⇒ D) ⇒ (F(Fix(F)) ⇒ D). And λr. r a ∈ Fix(F) ⇒ D, by abstract: if r ∈ Fix(F), then instantiate r at D and apply to a, so r a ∈ D. So a (λr. r a) ∈ F(Fix(F)) ⇒ D, and a (λr. r a) u ∈ D. The closure condition, twice, gives in u a ∈ D.

Fold. If z ∈ Fix(F), then z a ∈ D by instantiate and apply, so λz. z a ∈ Fix(F) ⇒ D by abstract. The head steps are (λz. z a) (in y) →h in y a, then in y a →h (λa. a (λr. r a) y) a, then one step to a (λr. r a) y. ∎

Remark · Why the encoding and the semantics are one set

Fix(F) is defined by what its members do if they are applied: it is an intersection of arrows. Quoted from Matthes’s thesis. He calls a set of terms that is defined in that way elimination-based, and one that is generated by the terms a constructor builds introduction-based; he observes that the type expression read off an elimination-based definition is the encoding of the type by ∀ and →, and that the proof that the introduction-based set is inside the elimination-based one is the encoded constructor; whether the encodings found in this way always keep the steps he leaves open. Measured against this page. Here the two are not only alike. Terms carry no annotations and using a member is applying it, so the elimination-based set of Mendler’s iteration and the set that the encoding names are one set, Fix(F), and in is the program of the inclusion.

The inductive part, for monotone F

Induction says more than fold: the result may mention the member itself, as in {{self}} and {{implicit}}. For that the recursion layer must be allowed to assume the induction hypothesis for the smaller things, and “smaller” now has to mean “inside the inductive type”, not “of any type set”. The index set of the intersection shrinks accordingly.

Definition · Proof algebras, and the inductive part

Let F be a monotone function from type sets to type sets, in the sense of {{more}}. For a type set C and a family Q, the proof algebras are

PrfAlg(C, Q) = ⋂D ⊆ C ( Πr∈D Q(r) ⇒ Πy∈F(D) Q(in y) )

an intersection indexed by the type sets D inside C, in the sense of {{ops}}; the index set contains Min, so it is not empty. Let

G(C) = { t : t ∈ Fix(F) and t ∈ ⋂Q (PrfAlg(C, Q) ⇒ Q(t)) }

with Q over all families, and let the inductive part Ind(F) be the least fixed point μG of {{more}}.

A member of PrfAlg(C, Q) turns a proof of Q for every member of a type set D inside C into a proof of Q(in y) for every y ∈ F(D). G(C) is a dependent intersection of {{dinter}}, whose second part is a family because each Q is.

Lemma · The inductive part, for monotone Fhere, reviewed

Let F be monotone.

type set
G is monotone, so Ind(F) = μG exists, is a type set, and equals G(Ind(F)). It is inside Fix(F).
in
in ∈ F(Ind(F)) ⇒ Ind(F).
induction
For every family Q and every p ∈ PrfAlg(Ind(F), Q): if e ∈ Ind(F), then e p ∈ Q(e). So λe. e p ∈ Πe∈Ind(F) Q(e).
out
Let out = λe. e (λf.λy.y). Then out ∈ Ind(F) ⇒ F(Ind(F)), and out (in u) reaches u by five head steps, however large u is.
Proof

Type set. If C ⊆ C′, then every D inside C is inside C′, so PrfAlg(C′, Q) ⊆ PrfAlg(C, Q), so PrfAlg(C, Q) ⇒ Q(t) ⊆ PrfAlg(C′, Q) ⇒ Q(t), because a smaller input set gives a larger arrow, and so G(C) ⊆ G(C′). Each G(C) is a type set by the lemmas of {{ops}}, {{darrow}} and {{dinter}}. So μG exists and G(μG) = μG, by {{more}}. It is inside Fix(F) by the definition of G.

Write V(t) for ⋂Q (PrfAlg(Ind(F), Q) ⇒ Q(t)), so that Ind(F) = { t : t ∈ Fix(F) and t ∈ V(t) }.

in. Take u ∈ F(Ind(F)). Since Ind(F) ⊆ Fix(F) and F is monotone, u ∈ F(Fix(F)), and in u ∈ Fix(F) by the lemma on the Mendler fixed point. For in u ∈ V(in u), take any family Q and p ∈ PrfAlg(Ind(F), Q). As before, in u p reaches p (λr. r p) u by two safe head steps. Instantiate p at D = Ind(F), which is inside itself: p ∈ Πr∈Ind(F) Q(r) ⇒ Πy∈F(Ind(F)) Q(in y). And λr. r p ∈ Πr∈Ind(F) Q(r), by abstract: if r ∈ Ind(F), then r ∈ V(r), so instantiate at Q and apply to p give r p ∈ Q(r). So p (λr. r p) u ∈ Q(in u), and the closure condition, twice, gives in u p ∈ Q(in u).

Induction. If e ∈ Ind(F), then e ∈ V(e), so e p ∈ Q(e) by instantiate and apply. Then abstract for the dependent arrow.

Out. Let Q be the constant family with value F(Ind(F)). Then λf.λy.y ∈ PrfAlg(Ind(F), Q): for any D inside Ind(F), any f ∈ Πr∈D F(Ind(F)) and any y ∈ F(D), the term (λf.λy.y) f y reaches y by two head steps, safe because f and y are in SN, and y ∈ F(D) ⊆ F(Ind(F)) because F is monotone. So by induction, e (λf.λy.y) ∈ F(Ind(F)) for every e ∈ Ind(F), and abstract gives out ∈ Ind(F) ⇒ F(Ind(F)). The head steps: out (in u) →h in u (λf.λy.y), then two steps to (λf.λy.y) (λr. r (λf.λy.y)) u, then two steps to u. ∎

Definition · The upper monotonization of F

Let F be any function from type sets to type sets. For a type set C, the upper monotonization of F at C is

F⊇(C) = ⋃D ⊆ C F(D)

the union of the type sets F(D) over the type sets D inside C.

The name is Matthes’s. Quoted from his thesis: the rules of Mendler’s system, in the variant that the thesis studies, are the rules of the least fixed point of F⊇, and not of F. That is why they need nothing of F: Mendler restricted his system to positive F, and Matthes proves strong normalization without the restriction.

Lemma · The inductive part, for any Fhere, reviewed

The definitions of PrfAlg, G and Ind(F) do not use that F is monotone. Read them for any function F from type sets to type sets. Then:

monotonization
F⊇(C) is a type set, F⊇ is monotone, F(C) ⊆ F⊇(C), and F⊇ = F if and only if F is monotone.
type set, induction
The items type set and induction of the lemma on the inductive part for monotone F hold as stated.
in
in is in F⊇(Ind(F)) ⇒ Ind(F), and so in F(Ind(F)) ⇒ Ind(F).
out
out is in Ind(F) ⇒ F⊇(Ind(F)): what out returns is in F(D) for some type set D inside Ind(F).

So in and out pass between Ind(F) and F⊇(Ind(F)) for every F, and the hypothesis that F is monotone does one thing only: it puts F in the place of F⊇ on both sides. The constructor and induction are free, as the constructor and fold of Fix(F) are. The form of in with F⊇ was pointed out by the reader of the sixth review.

Proof

Monotonization. The collection of the type sets inside C is not empty, because C is inside itself, so the union is a type set, by the union lemma of {{ops}}, and it contains F(C). A larger C has more type sets inside it, so F⊇ is monotone. If F is monotone, every F(D) with D ⊆ C is inside F(C), so the union is F(C); and if F⊇ = F, then F is monotone because F⊇ is.

Type set and induction. The proofs given for monotone F do not use the hypothesis: that G is monotone follows from the index set D ⊆ C alone, and induction is the definition of G read off.

in. Take u ∈ F(D′) for a type set D′ inside Ind(F). First, in u ∈ Fix(F). Take any type set D and any a ∈ Alg(F, D). The term in u a reaches a (λr. r a) u by two safe head steps, because u and a are in SN. Instantiate a at C = D′, and not at Fix(F) as the proof of the lemma on the Mendler fixed point did: a ∈ (D′ ⇒ D) ⇒ (F(D′) ⇒ D). And λr. r a ∈ D′ ⇒ D, by abstract: if r ∈ D′, then r ∈ Ind(F), so r ∈ Fix(F), and instantiate at D and apply give r a ∈ D. So a (λr. r a) u ∈ D, and the closure condition, twice, gives in u a ∈ D. Second, in u ∈ V(in u), where V(t) is ⋂Q (PrfAlg(Ind(F), Q) ⇒ Q(t)) as in the proof for monotone F. Take any family Q and p ∈ PrfAlg(Ind(F), Q), and instantiate p at the index D′, which is inside Ind(F): p ∈ Πr∈D′ Q(r) ⇒ Πy∈F(D′) Q(in y). And λr. r p ∈ Πr∈D′ Q(r), because r ∈ D′ gives r ∈ Ind(F), so r ∈ V(r) and r p ∈ Q(r). So p (λr. r p) u ∈ Q(in u); the term in u p reaches it by two safe head steps, and the closure condition gives in u p ∈ Q(in u).

Out. Let Q be the constant family with value F⊇(Ind(F)). Then λf.λy.y ∈ PrfAlg(Ind(F), Q): for any type set D inside Ind(F), any f in Πr∈D Q(r) and any y ∈ F(D), the term (λf.λy.y) f y reaches y by two safe head steps, and y ∈ F(D) ⊆ F⊇(Ind(F)), by the definition of the upper monotonization. So by induction, e (λf.λy.y) ∈ F⊇(Ind(F)) for every e ∈ Ind(F), and abstract gives the claim. ∎

Lemma · The inductive part, at any fixed pointhere, reviewed

Let F be any function from type sets to type sets, and let J be a type set with J = G(J).

any fixed point
The items in, induction and out of the lemma on the inductive part for any F hold with J in the place of Ind(F).
the greatest
G has a greatest fixed point νG, the union of all type sets C with C ⊆ G(C), and Ind(F) ⊆ νG ⊆ G(Fix(F)).

So the lemma on the inductive part for monotone F and the lemma for any F nowhere use that Ind(F) is the least fixed point. Matthes’s thesis says the like of the set that he defines by its eliminations: “µE(Φ) := any fixed point of ΨE”. His operator is the one of recursion, the Ψ of the lemma on Mendler recursion further on in this section, and not G; there too the proof uses only that Rec(F) is a fixed point of Ψ. He lists among his open problems: “Are there examples which show that µI(Φ) ≠ µE(Φ)?” The question of the closing remark, whether G(Fix(F)) and Ind(F) are the same type set, splits accordingly in two: whether G(Fix(F)) is a fixed point of G, in which case it is νG; and whether G has more than one fixed point. Both are open on this page.

Proof

Any fixed point. J ⊆ Fix(F), by the definition of G. The proof of the lemma for any F reads word for word with J for Ind(F). It uses J ⊆ G(J) where it says that a member r of the inductive part is in Fix(F) and in V(r), and it uses G(J) ⊆ J where it concludes that in u is a member. It never compares J with another fixed point.

The greatest. The collection of the type sets C with C ⊆ G(C) contains Min, because G(Min) is a type set, by the item type set of the lemma for any F, and Min is inside every type set. So its union νG is a type set, by the union lemma of {{ops}}. For every C in the collection, C ⊆ G(C) ⊆ G(νG), because G is monotone, so νG ⊆ G(νG); then G(νG) ⊆ G(G(νG)), so G(νG) is in the collection and G(νG) ⊆ νG. Every fixed point is in the collection, so Ind(F) ⊆ νG. And νG = G(νG) ⊆ Fix(F), so νG = G(νG) ⊆ G(Fix(F)), because G is monotone. ∎

Lemma · No predecessor into F(R), for an F that is not monotonehere, reviewed

Let T be a type set and let F(C) = C ⇒ T. Let R be a type set with in ∈ F(R) ⇒ R; Fix(F) and Ind(F) are such sets. Then no term P has both of these properties: P ∈ R ⇒ F(R); and P (in t) reaches t by steps, for every t ∈ F(R).

The term out has the second property, for every F. So for this F it is not in Ind(F) ⇒ F(Ind(F)), and the upper monotonization in the item out of the lemma for any F cannot be dropped. Here F gives a smaller set for a larger input, and F⊇(R) is Min ⇒ T. The proof uses of in only that it is in F(R) ⇒ R, so the lemma holds with any term of that set in its place, among them the constructor in+ of Mendler recursion further on in this section, with R = Rec(F). The argument is Matthes’s, who gives it for the type expression of his system that corresponds to this F; it is put in the words of this page here.

Proof

Suppose P has both. Let d = λx. P x x, with x a variable that is not free in P. For u ∈ R: P u ∈ R ⇒ T, so P u u ∈ T, and d u takes a safe head step to it, so d u ∈ T by the closure condition. So d ∈ R ⇒ T = F(R), hence in d ∈ R, hence d (in d) ∈ T, and T ⊆ SN. But d (in d) takes a step to P (in d) (in d), and P (in d) reaches d, so the term reaches itself by at least one step, and it is not in SN. With P = out a program finds the term back at itself after six head steps. ∎

Example · Mendler-style natural numbers

Let F(C) = ⋂D (D ⇒ ((C ⇒ D) ⇒ D)), the function of the example “Least fixed points” in {{more}}: F(C) contains the zero λz.λs.z and, for each n ∈ C, the successor λz.λs.s n, which carries its predecessor. It is monotone. Then

0 = in (λz.λs.z)   S = λn. in (λz.λs.s n)   pred = λe. out e 0 (λm.m)

By the lemma on the Mendler fixed point and the lemma on the inductive part for monotone F, 0 ∈ Ind(F), S ∈ Ind(F) ⇒ Ind(F), and pred ∈ Ind(F) ⇒ Ind(F): out e is in F(Ind(F)), instantiate it at D = Ind(F), and apply to 0 and to λm.m ∈ Ind(F) ⇒ Ind(F). And pred (S n) reaches n by ten head steps, whatever n is: one for pred, one for out, one that takes S n to in (λz.λs.s n), four for in and λf.λy.y, two that apply λz.λs.s n to 0 and to λm.m, and one for (λm.m) n. Induction holds with PrfAlg(Ind(F), Q) as the induction step: a member must give Q(in y) for every y ∈ F(D), among them the zero and the successors of members r ∈ D, from a proof of Q(r) for every r ∈ D.

The Church numerals of {{implicit}} have no such predecessor: there, as Firsov, Blair and Stump report, citing Parigot, computing the predecessor takes a number of steps that grows with the number. That is the reason Cedille uses this encoding. The claims about the Church numerals are quoted and not proved here.

Recursion without induction: the cast as an argument

Between fold, which Fix(F) has for nothing, and induction, which took families and a dependent intersection, there is recursion: the layer may use the smaller thing itself, and not only the result for it. Mendler’s rule for it hands the layer one more function, which says that the smaller things are members of the inductive type. In Cedille that function is a cast. Here it can be an ordinary argument, used by applying it.

Definition · Mendler recursion

Let F be any function from type sets to type sets. For type sets M and N, let

RecAlg(F, M, N) = ⋂C ((C ⇒ M) ⇒ ((C ⇒ N) ⇒ (F(C) ⇒ N)))

Ψ(M) = ⋂N (RecAlg(F, M, N) ⇒ N)

with C and N over all type sets. Rec(F) is the least fixed point μΨ of {{more}}.

The constructor is the term in+ = λu.λa. a (λy.y) (λr. r a) u.

Lemma · Mendler recursion, for any Fhere, reviewed

fixed point
Ψ is monotone, whatever F is. So Rec(F) is a type set and Rec(F) = Ψ(Rec(F)).
in
in+ ∈ F(Rec(F)) ⇒ Rec(F).
recursion
If a ∈ RecAlg(F, Rec(F), N), then λz. z a ∈ Rec(F) ⇒ N, and (λz. z a) (in+ y) reaches a (λy.y) (λr. r a) y by three head steps.
predecessor
For the F of the example “Mendler-style natural numbers” and any Z ∈ Rec(F), the term λe. e (λi.λf.λy. y Z i) is in Rec(F) ⇒ Rec(F), and applied to in+ (λz.λs.s n) it reaches n by head steps, in a number of steps that does not depend on n.

The layer a gets, besides the way λr. r a to handle a smaller thing, a function from the smaller things into Rec(F), and that function is run as the identity. No family, no dependent intersection and no condition on F is used; the price is one fixed point, of an operator that is monotone for nothing. It gives recursion and not induction: the type set of a result does not mention the member. The set and the argument are Matthes’s, from his proof of strong normalization for his variant of Mendler’s system, put here for untyped terms; the fixed point of his that corresponds to Rec(F) is the one that he defines by its eliminations, and he takes any fixed point for it: the items in, recursion and predecessor use only Rec(F) = Ψ(Rec(F)).

Proof

Fixed point. Ψ(M) is a type set by the arrow lemma and the intersection lemma of {{ops}}. Let M ⊆ M′. A larger input set gives a smaller arrow, and a larger output set a larger one. So, in three lines: C ⇒ M ⊆ C ⇒ M′, the output grew. Then (C ⇒ M′) ⇒ U ⊆ (C ⇒ M) ⇒ U for every type set U, the input grew, and so RecAlg(F, M′, N) ⊆ RecAlg(F, M, N). Then RecAlg(F, M, N) ⇒ N ⊆ RecAlg(F, M′, N) ⇒ N, the input grew again, and so Ψ(M) ⊆ Ψ(M′). Then {{more}} gives the fixed point.

in. Write R for Rec(F). Take u ∈ F(R), a type set N and a ∈ RecAlg(F, R, N). The term in+ u a reaches a (λy.y) (λr. r a) u by two safe head steps. Instantiate a at C = R. The term λy.y is in R ⇒ R. And λr. r a ∈ R ⇒ N, by abstract: if r ∈ R = Ψ(R), then instantiate at N and apply give r a ∈ N. So a (λy.y) (λr. r a) u ∈ N, and the closure condition, twice, gives in+ u a ∈ N. So in+ u ∈ Ψ(R) = R.

Recursion. If z ∈ R = Ψ(R), then z a ∈ N, and abstract. The head steps are one for λz and the two that the proof of the item in counts for in+ y a.

Predecessor. The term λi.λf.λy. y Z i is in RecAlg(F, R, R): for a type set C, i ∈ C ⇒ R, f ∈ C ⇒ R and y ∈ F(C), instantiate y at D = R, so that y Z i ∈ R, and three safe head steps lead to it. Then recursion with N = R. The run: the term reaches (λi.λf.λy. y Z i) (λy.y) (λr. r a) (λz.λs.s n), then (λz.λs.s n) Z (λy.y), then (λy.y) n, then n. A program counts nine head steps. ∎

A loop over a recursive type

The recursive type μF of {{more}} has no constructor and no built-in loop: a member is used with the term unchanged. A loop over all its members can still be written as a term, for the numbers of the example “Least fixed points” there, and it belongs to the set that its type expression would name.

Lemma · An iterator over the least fixed pointhere, reviewed

Let F(C) = ⋂D (D ⇒ ((C ⇒ D) ⇒ D)), as in {{more}}. Let it = λz.λs.λn. n A B B, where A is short for λb.z and B for λp.λb. s (p A b b).

member
it is in ⋂C (C ⇒ ((C ⇒ C) ⇒ (μF ⇒ C))).
runs
With the zero written λa.λf.a and the successor of n written λa.λf.f n: it z s (λa.λf.a) reaches z, and it z s (λa.λf.f n) reaches s (n A B B), by head steps.

The term B is handed to itself, and that is how the loop goes round without a fixed-point term. The proof uses a type set built by hand, so it shows that the judgment is true; whether the rules of {{more}} derive it was not settled. The lemma was found by a reader of Matthes’s thesis for this page and checked by the writer; the thesis does not have it, and a second reader found another such term independently. From general knowledge, not checked: a note of Abadi, Cardelli and Plotkin on types for these numbers treats the question of rules.

Proof

Runs. Three head steps take it z s n to n A B B. Then (λa.λf.a) A B B reaches A B and then z, and (λa.λf.f n) A B B reaches B n B and then s (n A B B).

Member. Fix a type set C, z ∈ C and s ∈ C ⇒ C, and read A and B with these two terms. B is in SN: p A b b is in Base, so in C, so s (p A b b) ∈ C. Let E = Gen({B}), and let X be the set of the terms p ∈ SN with p A e e ∈ C for every e ∈ E.

X is a type set. A member of Base applied to A, e, e is in Base, so in C. If p →h p′ is safe and p′ ∈ X, then p A e e →h p′ A e e is safe, so p A e e ∈ C by the closure condition, and p ∈ SN by R3 (safe head step).

F(X) ⊆ X. Let p ∈ F(X) and e ∈ E, and instantiate p at D = E ⇒ C. First, A ∈ E ⇒ C: A e′ takes a safe head step to z. Second, e ∈ X ⇒ (E ⇒ C). Take q ∈ X and e′ ∈ E. By M2 (generated), the head steps of e lead to B or to a member of Base. If to B, then e q e′ reaches B q e′ and then s (q A e′ e′) by safe head steps; q A e′ e′ ∈ C because q ∈ X, so s (q A e′ e′) ∈ C, and the closure condition gives e q e′ ∈ C. If to a member of Base, then e q e′ reaches a member of Base, which is in C. So p A e ∈ E ⇒ C, and p A e e ∈ C. Also p ∈ SN. So p ∈ X.

By induction for the least fixed point, in {{more}}, μF ⊆ X; that step needs F(X) ⊆ X and nothing else, and that F is monotone is not used in this proof. So for n ∈ μF, with e = B: n A B B ∈ C. Then abstract, three times, gives the claim. A program ran the iterator on the first five numbers. ∎

Remark · What Cedille’s casts do, and what replaces them here

Quoted. In Cedille the inductive part is built without a fixed point. Its proof algebras quantify over every type R together with a cast from R to the fixed point, a function that is provably equal to the identity; so its inductive part is, in the terms of this section, G(Fix(F)). Its induction principle for proof algebras over the inductive part itself is then derived by using the induction hypothesis for the members of R to build a cast from R into the inductive part. A cast is applied by introducing a dependent intersection [x, y {p}] whose two parts are joined by a proof p that the cast is the identity, and projecting; Cedille Core, from which {{equality}} takes its rules, replaced that annotation by the rule φ, which does the same retyping. Firsov, Blair and Stump also replace functoriality of F by an identity mapping, which lifts casts to casts.

Worked out for this page. Here a cast between type sets is an inclusion D ⊆ C, and it appears as a condition on the index set of the intersection, not as a hypothesis, because {{equality}} showed that φ is false in this semantics and limit 1 of {{limits}} says why a hypothesis cannot carry it. An identity mapping becomes the condition that F is monotone, which is needed only to put F in the place of F⊇, by the lemma on the inductive part for any F. G(Fix(F)), Cedille’s inductive part, has in and induction for proof algebras over Fix(F) by the same proof, with no fixed point. What it lacks is the passage to proof algebras over the inductive part itself, which is the step Cedille makes by building a cast from the induction hypothesis; and it is that passage that out needs, since λf.λy.y is a proof algebra over Ind(F) and not over Fix(F). A fixed point of G is what replaces the cast for induction; the least and the greatest both serve, by the lemma on the inductive part at any fixed point. For recursion without induction nothing has to replace it: there the cast is an argument, in Rec(F). Ind(F) is inside G(Fix(F)), because G is monotone and Ind(F) = G(Ind(F)) with Ind(F) ⊆ Fix(F); whether the two are the same type set was not settled for this page. The obstacle is the one of {{hyp}}: the induction principle of G(Fix(F)) quantifies over proof algebras p, and a p with a free variable at its head passes every requirement, so nothing about a member of G(Fix(F)) can be read off from the principle alone. The Mendler fixed point Fix(F) itself, its constructor and fold cost nothing and ask nothing of F, which is one of the points Firsov, Blair and Stump make, and it survives the move from rules to sets.
