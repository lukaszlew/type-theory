Self types are one more addition, at the price that the addition lemma of {{price}} states. Their set is built from a family, and they are the first of three ways on this page to give a term a type expression that mentions the term itself; {{dinter}} and {{implicit}} give the other two.

Addition · Self types

Set
For a family V, the set ιx.V(x) = { t : t ∈ V(t) } is what Fu and Stump call a self type. A member is checked against the type set that it selects itself.
Lemma
It is a type set. Of V it uses only that V is constant along safe head steps, which every family is. The SN condition and the Base condition hold because each V(t) is a type set. For the closure condition, let s →h s′ be safe. If s′ ∈ V(s′), then s ∈ V(s′) by the closure condition, and V(s′) = V(s), because V is constant along the safe head step.
Facts
If t ∈ ιx.V(x) then t ∈ V(t), and if t ∈ V(t) then t ∈ ιx.V(x). These are the definition read both ways, and they are the two rules of Fu and Stump’s self types, without their premise that the type expression is well formed. That premise is the price: with it dropped, nothing here is something a machine could check, as {{rules}} says of Curry style in general.

Example · Self types

Induction. With 0 = λs.λz.z and S = λn.λs.λz.s (n s z), combine this addition with the least fixed points of {{more}} to define Nat as the least type set satisfying

Nat = ιx. ⋂P ( StepP ⇒ (P(0) ⇒ P(x)) )
StepP = ⋂y∈Nat (P(y) ⇒ P(S y))

where P ranges over all families, and StepP is the intersection indexed by the members of Nat, in the sense of {{ops}}. The right-hand side is monotone in Nat: a larger Nat gives a smaller StepP, because the intersection has more members to satisfy, and a smaller StepP to the left of an arrow gives a larger set. So the least such type set exists. Then 0 ∈ Nat and S ∈ Nat ⇒ Nat. Every t ∈ Nat satisfies t s z ∈ P(t), for every family P, every s ∈ StepP and every z ∈ P(0). The type set of the result, P(t), mentions t itself. Without the self type it could not, and one would have iteration and not induction: a term applied t times, with no statement about t.

Remark · Why Fu and Stump moved away from self types

Quoted from their papers. In Fu and Stump’s System S every family variable is declared together with the terms it accepts, so the definition of Nat there declares P to accept the members of Nat, the type expression being defined, and it contains the terms 0 and S, which must be shown to be in Nat. The proof of strong normalization for System S erases every dependency on terms and proves Fω with type expressions defined in terms of themselves, replacing ιx.T by T. Stump’s later Calculus of Dependent Lambda Eliminations, the theory behind Cedille, replaces self types by three constructions: dependent intersections ιx:A.B, which {{dinter}} treats, implicit products, in {{implicit}}, and an equality between terms, in {{equality}}. He states two reasons for leaving self types: the erasure method “is not applicable to analyze a system with large eliminations”, that is, with type expressions computed from terms; and the circularity was one “which System S avoided by using an ad-hoc form of mutually recursive types”.

Worked out for this page. The construction in the example meets neither difficulty, because it gives up what caused them. Here P ranges over the families on all terms. That collection is fixed before Nat is, so Nat occurs only in a place where the least fixed point of {{more}} applies. So this page gives a model for the two self-type rules and for this definition of Nat, and not a model of System S as a whole: in System S a family accepts only the terms it is declared for, and the rule of System S for such definitions appears to allow more than the monotone recursion of {{more}}, which was not checked against the paper in detail.

As a set, a self type is the dependent intersection of {{dinter}} whose first part is SN: the set { t : t ∈ SN and t ∈ V(t) }.
