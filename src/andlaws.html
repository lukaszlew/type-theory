Lemma · Laws of ∩ on type setshere, reviewed

Let T, U and V be type sets, and let F give a type set F(C) for each type set C.

repeat
T ∩ T = T. In standard terms, ∩ is idempotent. This is true of any set, and it is listed because the remark at the end of this section is about systems that give it up.
same input
(T ⇒ U) ∩ (T ⇒ V) = T ⇒ (U ∩ V).
same result
(T ⇒ V) ∩ (U ⇒ V) = (T ∪ U) ⇒ V. T ∪ U is a type set, by the union lemma of {{ops}}.
instances
⋂C F(C) ⊆ F(T) ∩ F(U). The intersection of two instances contains the intersection of all of them.
Proof

Repeat holds for any set.

Same input. A term t is in the left side if and only if, for every u ∈ T, t u ∈ U and t u ∈ V. That is the right side.

Same result. A term t is in the left side if and only if t u ∈ V for every u ∈ T and for every u ∈ U, that is, for every u ∈ T ∪ U.

Instances. This is instantiate, used at T and at U. ∎

Example · ∧ records which input goes to which result

I ∈ (TI ⇒ TI) ∩ (TK ⇒ TK), with the two hand-built type sets of {{typeset}}. The term sends TI into TI, and TK into TK.

The arrow between the unions, (TI ∪ TK) ⇒ (TI ∪ TK), says less. It also contains λx.K, which sends every input to K. And λx.K is not in TI ⇒ TI: (λx.K) I →h K, and K ∉ TI.

Example · A law that is true and not derivable

By the law same input, the judgment x : (X→Y) ∧ (X→Z) ⊨ x : X → (Y ∧ Z) is true.

It is not derivable in System F with ∧. The term is a variable, so a derivation can use only the variable rule, the two ∧ rules and the two ∀ rules. Starting from (X→Y) ∧ (X→Z), these rules take it apart, put ∧ between the results, and add or remove a ∀ whose variable does not occur. An arrow into Y ∧ Z never appears.

The term λy.x y does get this type expression. With y : X added to the context, x y : Y and x y : Z are derivable, then “∧ in” gives x y : Y ∧ Z, and “→ in” gives λy.x y : X → (Y ∧ Z).

For this reason presentations of intersection types often add inclusions between type expressions as rules. That is subtyping, which {{more}} adds.

Remark · Intersection types that count uses

By the law repeat, A ∧ A names the same set as A. Some systems keep A ∧ A and A apart: a variable with A ∧ A is then used exactly twice, once for each part. They are called non-idempotent intersection types.

Quoted from Bernadet and Graham-Lengrand: in such a system a derivation gets strictly smaller with every step of the term. So strong normalization follows by counting, “without requiring reducibility techniques”, which are the techniques of this page. The size of a derivation also bounds the length of the longest run.

The semantics of this page cannot express this. A set does not record how many times a member is used.
