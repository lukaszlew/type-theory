Cedille’s third construction is an equality between untyped terms, written {t ≃ t′}, with rules that use a proof of an equation without running it. {{darrow}} had equality as a defined type expression, u ≡ v, whose proofs are used by applying them. That difference decides which of Cedille’s rules fit.

Definition · The equality type set

For terms u and v, E(u, v) is SN if u and v are convertible, and Min otherwise.

There is one more form of type expression: {t ≃ t′}, for any terms t and t′.

One clause is added:

⟦{t ≃ t′}⟧ρ = E(t[ρ], t′[ρ])

The two values are forced by the rules below. A true equation needs a closed member, for the rule β, and SN is the type set that asks least of one. A false equation should prove anything, for the rule δ, so it has to name the smallest type set, which is Min by M3 (smallest).

Lemma · The equality type sethere, reviewed

type set
E(u, v) is a type set, and it is constant along steps of u and of v.
true equation
If u and v are convertible, then I ∈ E(u, v).
closed member
E(u, v) has a closed member if and only if u and v are convertible.

So, by the addition lemma of {{price}} as extended in {{dep}}, Lemma N holds with the new form of type expression: the clause computes the set from its two term inputs, and E is constant along their steps. On closed members, E(u, v) agrees with the EQ(u, v) of {{darrow}}.

Proof

SN and Min are type sets, and a step does not change which terms a term is convertible with. I ∈ SN. SN has closed members and Min has none, by M3 (smallest). ∎

Cedille has five rules for the equality. They are quoted here from the paper on Cedille Core, with the terms erased, and with two changes: in Cedille, the proof β of a true equation may erase to any term at all, written β{s}, and here it erases to I; and Cedille’s convertibility includes the rule η, which {{terms}} left out, so “convertible” here is the convertibility of {{fam}}, by β alone. The name “Kleene trick” is Stump’s, after Kleene’s realizability, which accepts any number as a realizer of a true equation. K′ stands for λx.λy.y.

ς is symmetry. δ says that a false equation proves anything: B is any type expression. ρ is rewriting. φ is the Kleene trick. In ρ and φ the proof e does not appear in the conclusion. In δ, ρ and φ the conclusion is about a term that the premises say nothing about, except through the equation.

Lemma · Three of the five rules are true, and two are nothere, reviewed

The rules β, ς and δ are true. The rules ρ and φ are not.

Proof

β is the fact true equation. ς holds because E(u, v) = E(v, u).

δ. K and K′ are distinct normal forms, so they are not convertible, by the Church–Rosser theorem, quoted. So ⟦{K ≃ K′}⟧ρ = Min, and Min is inside every type set, by M3 (smallest). So if e[ρ] ∈ Min, then e[ρ] ∈ ⟦B⟧ρ.

ρ. Let Γ be e : {K ≃ I}, z : P I. The judgment Γ ⊢ z : P I is derivable by the variable rule, so it is true. The rule ρ, with B = P x, concludes Γ ⊢ z : P K. That judgment is false. Take ρ(e) = y, which is in Min = E(K, I); ρ(P) = VI, the family of {{fam}} that is SN at the terms convertible with I and Min elsewhere; and ρ(z) = I, which is in VI(I) = SN. Then z[ρ] = I, and I ∉ VI(K) = Min.

φ. Let Γ be e : {I ≃ K}. The judgment Γ ⊢ I : ∀X.X→X is derivable, so it is true. The rule φ concludes Γ ⊢ K : ∀X.X→X. That judgment is false: take ρ(e) = y ∈ Min = E(I, K), and K ∉ ID, because K I →h λb.I, which is not in TI, so K ∉ TI ⇒ TI. ∎

Why ρ and φ fail is limit 1 of {{limits}} again. Each draws a conclusion from the existence of a member of {t ≃ t′}. In this semantics that existence says nothing, because the variables are members of every type set, and in particular of E(K, I) = Min. The rule δ draws its conclusion from Min itself, which is inside every type set, and that is why it is true. And a proof e of u ≡ v in {{darrow}} is used by applying it, e s ∈ P v, which is true even for e = y, because y s ∈ Base.

The rule φ fails for a second reason, which holds even for a true equation with a closed proof. It asks that if u ∈ T, and u and v are convertible, then v ∈ T: every type set would have to be closed under conversion. Not even SN is: (λz.I) Ω is convertible with I, by one step, and it is not in SN. Inside SN the same thing happens, as limit 3 of {{limits}} shows: Gen({I I}) contains I I and not I.

Lemma · With β and φ, a closed term that is not in SN is typablehere, reviewed

With the rules β and φ added to those of {{dep}}, the judgment ⊢ (λz.I) Ω : ∀X.X→X is derivable. The term (λz.I) Ω is closed, and it is not in SN, because Ω can be run inside it forever. So C1 (strong normalization) is false for these rules, and no semantics that proves C1 can make both β and φ true.

Proof
LineJudgmentRule
1⊢ I : {I ≃ (λz.I) Ω}β, since (λz.I) Ω → I
2⊢ I : ∀X.X→Xvariable, → in, ∀ in
3⊢ (λz.I) Ω : ∀X.X→Xφ, from 1 and 2

Line 3 is the false one: (λz.I) Ω ∉ ID, because ID ⊆ SN. Stump’s own example uses δ in the place of β, under a hypothesis. From e : {K ≃ K′}, δ gives e : {I ≃ Ω}, then φ gives e : {K ≃ K′} ⊢ Ω : ∀X.X→X, and “→ in” gives ⊢ λe.Ω : {K ≃ K′} → ∀X.X→X. ∎

Stump says the same of Cedille, quoted: “There are typable terms t which fail to normalize”, and “failure of normalization does not impinge on” the consistency theorem. So the failure is not a defect of this semantics. It is in what the rules ask for.

Remark · What Stump’s semantics for Cedille does instead

Quoted. A type names a set of closed terms that is closed under conversion, and every closed term is allowed, “even non-normalizing ones”. The equality type {t ≃ t′} names the set of all closed terms if the two terms are convertible and the empty set otherwise. What is proved is consistency: no closed term has the type expression ∀X.X.

Measured against this page. Three differences, each of which answers one failure above.

  • No variables, so no Base condition and no limit 1. A context with a false equation has no instance, and a judgment under it is true for lack of instances. That is what makes ρ and φ true there.
  • Closed under conversion, so no limit 3. This is also why the terms cannot be restricted to SN: the arrow of two sets that are closed under conversion need not be closed under conversion inside SN. For example, λx.y and λx.(λz.y) (x x) are convertible, and λx.y ∈ SN ⇒ SN, but (λx.(λz.y) (x x)) δ runs to (λz.y) Ω, which is not in SN.
  • The empty set is allowed as the set that a type expression names. Narrow point 2 in {{simpler}} showed what that costs: ∅ ⇒ SN is the set of all terms, so membership says nothing about strong normalization. Stump’s semantics pays that price and gets consistency for it.
