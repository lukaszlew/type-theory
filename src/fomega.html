Definition · Type expressions of higher kind

Fω has three more forms of type expression: an abstraction λX:κ.A, an application A B, and ∀X:κ.A for any kind κ.

A well-formed type expression has a kind, written A : κ. The rules are the usual ones:

  • Each variable X comes with a kind.
  • If A : κ′, then λX:κ.A : κ → κ′.
  • If A : κ → κ′ and B : κ, then A B : κ′.
  • If A : ∗ and B : ∗, then A → B : ∗.
  • If A : ∗, then ∀X:κ.A : ∗.

A step of a type expression rewrites a type expression (λX:κ.A) B inside it to A[B/X].

The symbols ∗ and κ → κ′ are written inside type expressions here. There they are names for the kinds of {{kinds}}.

An assignment ρ now sends each variable to a member of its kind, and three clauses are added:

⟦λX:κ.A⟧ρ = the function c ↦ ⟦A⟧ρ[X↦c]
⟦A B⟧ρ = ⟦A⟧ρ applied to ⟦B⟧ρ
⟦∀X:κ.A⟧ρ = ⋂c∈κ ⟦A⟧ρ[X↦c]

Example · A type expression that names a function

λX:∗. X → X names the function C ↦ C ⇒ C, a member of ∗ → ∗. λX:∗. X → Y has a free variable. With ρ(Y) = SN it names C ↦ C ⇒ SN, and another assignment gives another function.

Example · Two type expressions, one set

(λX:∗. X → X) (∀Y:∗. Y → Y) names the function C ↦ C ⇒ C applied to ID, which is ID ⇒ ID. The type expression (∀Y:∗. Y → Y) → (∀Y:∗. Y → Y) names the same set. The two differ by one step inside the type expression.

Example · Quantifying over a function on type sets

∀F:∗→∗. ∀X:∗. F X → F X names the intersection over a kind from {{kinds}}. So I is in it.

Lemma N · Extended to kindstextbook

N1
Member of its kind. If A : κ, then ⟦A⟧ρ is a member of κ.
N2
Substitution. ⟦A[B/X]⟧ρ = ⟦A⟧ρ[X↦⟦B⟧ρ].
N3
Type steps. (λX:κ.A) B and A[B/X] name the same thing. So do any two type expressions joined by such steps.
Proof

N1 is by induction on the rules that give A its kind. An abstraction names a function into the right kind. An application applies a function to a member of its domain. The ∀ case is the intersection lemma. N2 is by induction on A.

N3. By the clauses for λ and for application, (λX:κ.A) B names ⟦A⟧ρ[X↦⟦B⟧ρ]. By N2 (substitution) that is ⟦A[B/X]⟧ρ. A step inside a larger type expression changes nothing either, because what a type expression names is computed from what the type expressions inside it name. ∎

Addition lemma · Extended to parts of higher kindhere, reviewed

A part of an addition may now name a member of any kind. The addition lemma of {{price}} holds with its hypothesis read for kinds, that the operation of the clause gives a member of the form’s kind for all inputs that are members of their kinds, and with N1 read as “member of its kind” and N3 (type steps) added to its conclusion: a step inside a part changes nothing, because the clause computes from what the parts name, and by N3 that is unchanged.

Theorem · The rules that changetextbook

The theorem and both corollaries hold for System Fω. Its two ∀ rules carry a kind, and there is one new rule.

RuleFromConclude
∀ inΓ ⊢ t : A, with X not free in ΓΓ ⊢ t : ∀X:κ.A
∀ outΓ ⊢ t : ∀X:κ.A and B : κΓ ⊢ t : A[B/X]
conversionΓ ⊢ t : A, and A, B joined by steps inside type expressionsΓ ⊢ t : B

Every type expression in a judgment has the kind ∗. The rule of conversion also needs that a step takes a well-formed type expression of kind κ to a well-formed type expression of the same kind, so that B names a member of ∗. That is subject reduction for the kinding rules, which are the rules of the simply typed λ-calculus one level up; it is a textbook fact, quoted here and not proved.

Proof

∀ in and ∀ out are generalize and instantiate over the kind κ. Instantiate is used at ⟦B⟧ρ, which is a member of κ by N1 (member of its kind). Conversion holds because A and B name the same set, by N3 (type steps). The corollaries use the SN condition and the Base condition exactly as they do for System F. ∎

Remark · What was not needed

The proof never asks whether type expressions are strongly normalizing under their own steps. The set that a type expression names is defined by recursion on the type expression, so it exists either way. That they are strongly normalizing is a separate fact and an easier one. The type expressions of Fω form a simply typed λ-calculus, in which the kinds play the role of type expressions, and that is the case Tait’s method was made for, the one in Harper’s note of {{harper}}. It matters for checking derivations by machine, and not for C1 (strong normalization).

The cost is in the metatheory, the theory in which this proof is carried out. Each level of kinds needs the set of all functions on the level below, which amounts to one more power set.
