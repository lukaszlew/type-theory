System F is now a notation for some of these sets, together with a list of facts about them.

Definition · Type expressions are names

A type expression is a variable X, an arrow A → B, or ∀X.A. The variables X, Y of type expressions are a second sort of variable, separate from the variables of terms, which are called term variables from here on. The arrow groups to the right, so X→X→X means X→(X→X).

In ∀X.A the variable X is bound. A variable is free in a type expression if it occurs there outside every ∀X.

A type expression is closed if no variable is free in it.

A[B/X] is A with B in place of every free occurrence of X.

An assignment ρ gives a type set ρ(X) for each variable X.

The set that a type expression names under ρ is:

⟦X⟧ρ = ρ(X)
⟦A → B⟧ρ = ⟦A⟧ρ ⇒ ⟦B⟧ρ
⟦∀X.A⟧ρ = ⋂C ⟦A⟧ρ[X↦C]

Here ρ[X↦C] is ρ changed to send X to C. The third clause needs each ⟦A⟧ρ[X↦C] to be a type set. Lemma N, which follows the examples, proves that.

Example · One type expression, two assignments

Take the type expression X → X.

  • With ρ(X) = SN it names SN ⇒ SN.
  • With ρ(X) = TK it names TK ⇒ TK.

I is in both sets. λx.I is in SN ⇒ SN and not in TK ⇒ TK: it sends K to a term whose head step leads to I, and I is not in TK. A type expression with free variables names a different set for each assignment.

Example · Closed type expressions

A type expression without free variables names the same set under every assignment. ∀X.X→X names ID. ∀X.X names Min. ∀X.X→X→X names BOOL.

Example · Working out a named set

∀X.∀Y.X→Y names ⋂C ⋂D (C ⇒ D), and that set is SN ⇒ Min. Every C ⇒ D contains SN ⇒ Min: a term that sends SN into Min sends C into D, because C ⊆ SN and Min ⊆ D. And SN ⇒ Min is one of the sets intersected. It contains the variable y and no closed term: a closed member applied to I would be a closed member of Min.

Lemma N · Every type expression names a type settextbook

N0
Free variables. If ρ and ρ′ agree on the free variables of A, then ⟦A⟧ρ = ⟦A⟧ρ′.
N1
Type set. ⟦A⟧ρ is a type set, for every type expression A and every ρ.
N2
Substitution. ⟦A[B/X]⟧ρ = ⟦A⟧ρ[X↦⟦B⟧ρ]. Replacing X by the type expression B names the same set as sending X to the set that B names. For example, (X → X)[∀Y.Y→Y / X], and X → X with ρ(X) = ID, both name ID ⇒ ID.
Proof

All three by induction on A. For N1 (type set), a variable names ρ(X), which is a type set by assumption. An arrow is covered by the arrow lemma, and ∀ by the intersection lemma. N0 (free variables) and N2 (substitution) are unfolding the three clauses. The ∀ case of N2 (substitution) uses N0 (free variables), because the bound variable can be taken to be not free in B. ∎
