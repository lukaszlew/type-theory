“One lemma per addition” is true, and the lemma is not a formality. There are four limits.

Limit 1 · True rules about the wrong set are worthless

Try
Add a name for a set that is not a type set, together with rules that are true of that set.
Breaks
Narrow point 6 did this with Empty, a name for ∅, and typed the looping term λx.Ω.
Lesson
The lemma “the new set is a type set” carries the weight, and it is not a formality. A type set for “false” can be no smaller than Min, which has no closed member and still contains the variables.

Limit 2 · Some sets do not exist

Try
A type set T with T = T ⇒ T, so that every untyped term is typable.
Breaks
For such a T, any u ∈ T is also in T ⇒ T, so u u ∈ T, so δ ∈ T ⇒ T = T by abstract. Then δ δ ∈ T, against the SN condition.
Lesson
No type set satisfies the equation. Fixed points exist for monotone F, as {{more}} shows, and C ⇒ C is not monotone in C.

Limit 3 · Only strong normalization is certified

Try
Read t ∈ T as all that typing usually promises, including that t stays in T while it runs.
Breaks
Take T = Gen({I I}) from {{typeset}}. I I ∈ T and I I → I, but I ∉ T.
Lesson
Type sets are closed under undoing safe head steps. They are not closed under steps. The statement “if t : A and t → t′ then t′ : A”, called subject reduction, is known to hold for plain System F, by a separate proof about derivations. It is known to fail for the rule that uses a member of an existential type, in {{more}}.

Limit 4 · New forms of terms reopen the definition

Try
Add pairs with projections, or built-in numbers with a recursor, as a few more rules.
Breaks
The Base condition and the closure condition list forms of terms: a variable applied to arguments, an abstraction applied to arguments. With pairs, fst x is a new form with no head step, and fst ⟨t,u⟩ → t is a new head step that throws u away. Narrow point 3 comes back for it.
Lesson
Lemma R and the three conditions have to be restated for the new terms, and {{ops}} checked again. It is the same work as in {{typeset}} and {{ops}}, and no harder. But it is the definition again, and not one more lemma on top of it.

One more observation on cost. Every intersection over all type sets uses the same strong principle as narrow point 5. The additions do not need more than that.
