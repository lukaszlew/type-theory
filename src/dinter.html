Definition · Dependent intersection

For a type set T and a family V, the dependent intersection is the set { t : t ∈ T and t ∈ V(t) }.

There is one more form of type expression: ιx:A.B, where the term variable x may be free in B.

One clause is added:

⟦ιx:A.B⟧ρ = { t : t ∈ ⟦A⟧ρ and t ∈ ⟦B⟧ρ[x↦t] }

Two rules are added:

RuleFromConclude
ι inΓ ⊢ t : A and Γ ⊢ t : B[t/x]Γ ⊢ t : ιx:A.B
ι outΓ ⊢ t : ιx:A.BΓ ⊢ t : A, and also Γ ⊢ t : B[t/x]

The second part may mention the term itself. A ∧ B is the case in which x is not free in B. The form and its rules are Kopylov’s.

Lemma · The dependent intersection is a type sethere, reviewed

If T is a type set and V is a family, then { t : t ∈ T and t ∈ V(t) } is a type set. Of V the proof uses only that it is constant along safe head steps.

So, by the addition lemma of {{price}} as extended in {{dep}}, Lemma N holds with the new form of type expression, and with the two new rules the soundness theorem and both corollaries hold.

Proof

SN condition. The set is inside T.

Base condition. A member s of Base is in T and in V(s), because both are type sets.

Closure condition. Let s →h s′ be safe, with s′ ∈ T and s′ ∈ V(s′). Then s ∈ T, by the closure condition for T. Also s ∈ V(s′), by the closure condition for V(s′). And V(s′) = V(s), because V is constant along the safe head step. So s ∈ V(s).

The addition lemma. The clause computes the set from the type set that A names and the family w ↦ ⟦B⟧ρ[x↦w], by the dependent intersection, which gives a type set by the first part and has no term input. So the extended addition lemma gives Lemma N. The two rules are true: by N2 (substitution), ⟦B[t/x]⟧ρ = ⟦B⟧ρ[x↦t[ρ]], so t[ρ] is in ⟦A⟧ρ and in ⟦B[t/x]⟧ρ if and only if it is in ⟦ιx:A.B⟧ρ. ∎

Example · Two cases of the dependent intersection

  • If V is the constant family V(u) = U, then the dependent intersection is T ∩ U.
  • If T is SN, then it is { t : t ∈ V(t) }, because every V(t) is inside SN. That is the self type of {{self}}.

So the dependent intersection contains both ∧ and the self type as cases. Stump’s Calculus of Dependent Lambda Eliminations has ιx:A.B in the place of self types, as the remark in {{self}} reports.
