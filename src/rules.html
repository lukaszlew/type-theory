Definition · The rules of System F

System F has five rules. Each rule concludes one judgment from at most two others.

RuleFromConclude
variablex:A is in ΓΓ ⊢ x : A
→ outΓ ⊢ t : A→B and Γ ⊢ u : AΓ ⊢ t u : B
→ inΓ, x:A ⊢ t : BΓ ⊢ λx.t : A→B
∀ inΓ ⊢ t : A, with X not free in ΓΓ ⊢ t : ∀X.A
∀ outΓ ⊢ t : ∀X.AΓ ⊢ t : A[B/X]

Γ, x:A is the context Γ with x:A added at the end.

A derivation is a finite list of judgments in which each judgment follows from earlier ones by one of the rules.

A judgment is derivable, written Γ ⊢ t : A, if it is the last judgment of a derivation.

A term t is typable if Γ ⊢ t : A is derivable for some Γ and some A. The rules then give t the type expression A.

A rule is true if the following holds: if the judgments it starts from are true, then the judgment it concludes is true.

The two ∀ rules leave the term unchanged. This way of presenting System F, with no annotations inside terms, is called Curry style.

Example · What a side condition prevents

x : X ⊨ x : X is true. x : X ⊨ x : ∀X.X is false: send X to SN and replace x by I, and recall that ∀X.X names Min. The rule “∀ in” would lead from the true judgment to the false one if it did not require that X is not free in the context.

Soundness theorem · The rules of System F are truetextbook

If Γ ⊢ t : A, then Γ ⊨ t : A.

Each rule except the variable rule is one of the four facts of {{facts}}. “→ out” is apply, “→ in” is abstract, “∀ in” is generalize, and “∀ out” is instantiate.

Proof

By induction on the derivation, with one case per rule. In each case the variables of Γ have been replaced by members of their sets.

  • Variable. The term that replaces x was taken from ⟦A⟧ρ.
  • → out. Apply.
  • → in. Abstract. The bound variable x is renamed if needed, so that it is not a variable of Γ and not free in the terms that replace them.
  • ∀ in. Generalize. Because X is not free in Γ, the sets ⟦Ai⟧ρ do not change while ρ(X) varies, by N0 (free variables). So the terms that replace the variables stay in their sets.
  • ∀ out. Instantiate at D = ⟦B⟧ρ, which is a type set by N1 (type set). Then N2 (substitution) turns the result into ⟦A[B/X]⟧ρ. ∎

Corollaries · Strong normalization and consistencytextbook

C1
Strong normalization. If Γ ⊢ t : A, then t is strongly normalizing.
C2
Consistency. No closed term t has ⊢ t : ∀X.X.

C1 (strong normalization) holds because the variables are members of every type set, so each variable can be replaced by itself. C2 is called consistency for this reason: read as a statement, ∀X.X says that everything holds, and a closed term t with ⊢ t : ∀X.X would be a proof of it.

Proof

C1. Pick any ρ. Replace each variable xi by itself. That is allowed because xi ∈ ⟦Ai⟧ρ by the Base condition. The theorem gives t ∈ ⟦A⟧ρ, and t ∈ SN by the SN condition.

C2. Such a term would be in Min, which has no closed member. The word “closed” costs nothing here: a term t with ⊢ t : A is always closed, because a free variable can enter a derivation only through the variable rule, which takes it from the context. ∎

Example · A derivation and what it certifies

Write J for the type expression ∀X.X→X. It names the type set ID.

Example · A typed term that copies a lot

two is the term λf.λx.f (f x).

N is the type expression ∀X.(X→X)→(X→X).

⊢ two : N is derivable, by two uses of “→ out”, two of “→ in” and one of “∀ in”. The derivation follows the example “The four facts at work” in {{facts}} line for line. Then ⊢ two two : N is derivable: “∀ out” with B = X→X for the first two, “∀ out” with B = X for the second, then “→ out”, then “∀ in”. In the same way ⊢ two two two : N. By C1 (strong normalization) this term is strongly normalizing, although its runs copy two again and again before they stop.

Remark · Where the context is

Type sets are not indexed by a context. A variable is an untyped term, and by the Base condition it belongs to every type set, whatever type expression a context might give it. That does no harm, because a variable does nothing: it has no step. The context appears in two places only. In a judgment it is the list of sets that the replacing terms are taken from. In a derivation it is the list of variables that the term may have free. C2 (consistency) uses that: a term derived in the empty context is closed.

This is what lets the sets come before the rules. A set that depended on the type expressions of its variables would need those first. Proofs about typed terms cannot avoid this: a set of well-typed terms with free variables has to say which context types those variables, and to pass under a λ it has to survive the extension of that context. Quoted from Abel, Öhman and Vezzosi, whose proof decides equality of typed terms for a dependent type theory and computes no more of a term than the form its head steps lead to: “A logical relation on well-typed open terms is necessarily Kripke, i.e., closed under weakening”; “Otherwise, the Fundamental Theorem would fail for binders”.

Remark · Church style: System F with annotations

System F is often written with type expressions inside terms: λx:A.t, an abstraction ΛX.t over a variable of type expressions, and its application t [B] to a type expression. Erasing these annotations gives a term that the five rules accept. Every step of the annotated calculus either erases to a step, or is a step (ΛX.t) [B] → t[B/X], which erases to nothing and removes one Λ. So between two steps that erase to steps there are at most as many steps that erase to nothing as the term has Λs, an infinite run with annotations would give an infinite run without them, and C1 (strong normalization) covers both presentations. This argument was worked out for this page.

Curry style has a price. A derivation cannot be read off the term, so nothing on this page is something a machine could check from the term alone; and systems whose terms carry type expressions that contain terms again are covered only through an erasure argument of this kind, which {{erasure}} states in general.

Remark · What the proof asked of the collection that ∀ ranges over

The proofs of Lemma N, of the four facts, of the soundness theorem and of its corollaries use five things about the collection of all type sets, and nothing else: that every member satisfies the three conditions of {{typeset}}; that the arrow of two members is a member; that the intersection of a nonempty set of members is a member; that the collection itself is not empty, so that ∀ is such an intersection; and, for C2 (consistency), that the smallest member of the collection, which is what ∀X.X names, has no closed member. For the collection of all type sets that member is Min. Any collection of type sets with these properties could take the place of the collection of all type sets as the range of ∀, with assignments taking their values in it, and the results would hold with the same proofs. {{families}} does this for two smaller collections, and {{tests}} for a third. This page keeps the largest one, because it asks the least of a set; {{families}} says what the smaller ones give in return.

Remark · What the proof asked of terms

The same proofs use, about terms, only the following, and nothing else about what a term is. Lemma R of {{head}}: R1 (subterms), R2 (variable applied) and R3 (safe head step). That a head step survives one more argument, with the same argument. That (λx.t) u takes a head step to t[u/x], with argument u. That a variable is in Base, that a member of Base applied to a member of SN is in Base, and that a member of Base has a free variable. And, for M2 (generated), that a member of cl(S) reaches S by safe head steps. The list was made by reading the proofs of {{typeset}} to this section, and it is the list that {{pairs}} checks for pairs of terms. Anything with an application, an abstraction, a notion of step and a set Base for which these hold carries the theory: pairs of terms, and in the same way lists of any fixed length, which give relations between several terms; and terms with further forms, such as pairs or numbers inside them, once Lemma R and the three conditions have been restated for the new forms, which is what limit 4 of {{limits}} says has to be done. Combinators, terms built from S, K and application with no abstraction at all, carry it too, with the facts about S and K in the place of abstract: K u v and S u v w take head steps that discard or copy an argument, exactly as (λx.t) u does, and the three conditions are stated for those head steps; this was not written out for this page. What the list does not mention is as telling: that a term has one of three forms, or that steps are confluent, is never used on the main line. A different route is open whenever a translation into terms sends each step of the other system to one or more steps, or to none with only finitely many such in a row: then the erasure lemma of {{erasure}} gives strong normalization for the other system from the theorem for terms, with no semantics of its own.
