The definition of a type set in {{typeset}} is one of several. This section puts it beside Girard’s original definition and beside the plainest idea, which fails.

Saturated sets and reducibility candidates

The type sets of {{typeset}} are Tait’s saturated sets. Girard’s own proof used a different collection of sets in the same role.

Definition · Reducibility candidate

A term is neutral if it is not an abstraction.

A reducibility candidate is a set T of terms such that:

CR1
every member of T is in SN;
CR2
if t ∈ T and t → t′, then t′ ∈ T; Membership survives every step.
CR3
if t is neutral and every term that t steps to is in T, then t ∈ T. A variable is neutral and has no step, so every candidate contains every variable.

Lemma · Candidates are the type sets that are closed under stepshere, reviewed

Every reducibility candidate is a type set. Every type set satisfies CR1 and CR3. So a type set is a reducibility candidate if and only if it satisfies CR2, and CR2 is the only one of the three that a type set can fail.

Proof

A candidate is a type set. The SN condition is CR1. In the Base condition and the closure condition the term in question is neutral, so by CR3 it is enough that every term it steps to is a member.

For the Base condition, every step of x u1…un is inside an argument and gives a term of the same form. Argue by induction on the total length of the longest runs of the arguments.

For the closure condition, write s for (λx.t) u u1…un and s′ for t[u/x] u1…un, with s′ ∈ T and u ∈ SN. The head step takes s to s′. Any other step is inside t, u or some ui, and gives a term of the same form as s. The term after the head step of that term is reached from s′ by zero or more steps, so it is in T by CR2. Argue by induction on the longest runs of s′ and of u.

Every type set satisfies CR1 and CR3. CR1 is the SN condition. For CR3, let t be neutral with every term it steps to in T. Those terms are in SN, so t ∈ SN. A neutral term is either a variable applied to arguments, and then it is in T by the Base condition, or it has a head step. In that case the term after the head step is in T and the argument is in SN, so t ∈ T by the closure condition. ∎

Example · A type set that is not a candidate

Gen({I I}) from {{typeset}} contains I I and does not contain I, although I I → I. So it fails CR2. The reverse cannot happen in either collection: a set that contains I contains I I, by the closure condition. SN is both a type set and a candidate, by R1 (subterms).

Both collections are closed under ⇒ and under intersections, so either one proves the theorem, through the same four facts. For candidates the reason is short. If T and U are candidates, then T ⇒ U is a type set by the arrow lemma, and it satisfies CR2: if t ∈ T ⇒ U and t → t′, then for every u ∈ T the term t u is in U and steps to t′ u, so t′ u ∈ U by CR2 for U. CR2 passes to intersections, because it holds in each set. Neither is better throughout. Candidates keep a term while it runs. And CR3 names no form of term except “not an abstraction”, so if new forms of terms are added, as in limit 4 of {{limits}}, then it is enough to say which of them are neutral. Saturated sets are closed under unions by a proof of one line, which the existential types of {{more}} need. For candidates the union is a candidate too: by the lemma “Candidates are the type sets that are closed under steps”, two candidates are two type sets closed under steps, their union is a type set by the union lemma of {{ops}}, and it is closed under steps because each of the two is. The conditions of saturated sets are also direct statements about membership, which keeps each closure proof to a line.

That the union of two candidates is a candidate is a theorem of Riba’s, from 2007. He writes that the property “was hitherto unknown, and even often believed to be false”, and proves it for the Curry-style second-order λ-calculus, which is the setting of this page; there he also shows that the candidates are exactly the saturated sets that are closed under steps, which is the lemma “Candidates are the type sets that are closed under steps”. The same statement is in Matthes’s thesis of 1998, for typed terms and without its proof: “Girard’s candidates are nothing but saturated sets which are closed under reduction”. The same pages say of Tait’s own sets of 1975 that they “are also closed under reduction but this is never used in his proof of strong normalization”, and credit Altenkirch with the step to sets that are closed only under undoing head steps inside SN, which are the type sets of this page. Riba’s theorem is more general: for a rewriting system in which candidates make sense, they are closed under union if and only if they are exactly the nonempty sets of strongly normalizing terms that are closed downward under a certain preorder on terms, which can fail elsewhere. The two-line proof of this paragraph is this page’s, and it uses that lemma in the place of his argument.

With the two collections a type expression names two sets, because ∀ is an intersection over a different collection in each. For ∀X.X both sets are Min, which belongs to both collections and is inside every member of each. For other type expressions this page does not know whether the two sets can differ; both contain every term that the rules give that type expression.

Plain sets

The plainest idea is to drop the conditions and let every set be a type set. There are two versions.

Any set of terms. Keep the terms and keep ⇒. Then ∅ is a type set, and ∅ ⇒ U is the set of all terms, as in narrow point 2. So membership says nothing about strong normalization. The rule “→ in” fails as well, because it rests on the closure condition. For example, let T = U = {y}. Then x[u/x] ∈ U for the only u ∈ T, but (λx.x) y is not the term y, so λx.x ∉ T ⇒ U.

Any set, with all functions. Leave the terms out. A type expression names a set of values of any sort, and A → B names the set of all functions from the one set to the other. For the simply typed λ-calculus this is the standard model. For System F no such model exists. This is Reynolds’s theorem of 1984, “polymorphism is not set-theoretic”, quoted here and not proved. Its proof is by counting. A model would contain a set P that is as large as the set of all functions from P → B to B, where B has two members, and Cantor’s theorem forbids that. Pitts later showed that the theorem depends on classical logic.

Sets of terms escape because their arrow is small. T ⇒ U contains terms only, and there are countably many terms, however many functions there are from T to U. Every type set is a subset of one countable set. So the collection of all type sets is a set, and an intersection over it is an ordinary operation.

{{kinds}} reads kinds in the plain way: ∗ is a set, and κ → κ′ is the set of all functions. If no kind quantifies over all kinds, then this causes no trouble. Narrow point 7 in {{allkinds}} is what happens when one does, and it ends in the same appeal to Cantor’s theorem.
