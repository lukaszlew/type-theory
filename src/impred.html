Narrow point 5 in {{allsets}} said that the intersection over all type sets is impredicative: it defines a type set by quantifying over a collection that contains that type set. {{strength}} said what that costs, more than second-order arithmetic. The same move is made in several more places on the page, each time with a different index set. This section lists them and shows that the price is paid once, with the kinds of Fω as the one exception.

Lemma · Every intersection on this page is over a sethere, reviewed

Every intersection that this page forms is indexed by one of the following sets, or by a subset of one of them: a type set, which is a set of terms; the collection of all type sets; the collection of all families; a kind of {{kinds}}. Each of these is a set in ordinary set theory. The type sets and the families are both subsets of one power set of a set of terms or of pairs of terms; a kind is built from the type sets by one more power set for each arrow in it.

So the circle of narrow point 5 is always the same circle: a set is defined by an intersection over a collection, and the collection was fixed, as a set, before the definition. The one collection that is not a set is that of all kinds, and narrow point 7 in {{allkinds}} is what happens when an intersection is taken over it.

Proof

The intersections on the page are: over all type sets, in {{ops}}; over a nonempty set of type sets, for ∧ in {{and}} and for the fixed point of {{more}}, which intersects the type sets C with F(C) ⊆ C; over all families, in {{fam}}; over the members of a type set, in {{self}} and {{implicit}}, which is a subset of the set of all terms; over the type sets inside a given one, over all type sets and over all families again, in {{induct}}; and over a kind, in {{kinds}}. A type set is a subset of the set of terms, so the type sets form a subset of its power set. A family V is determined by the set of pairs (u, t) with t ∈ V(u), which is a subset of the set of pairs of terms; so the families form, up to this coding, a subset of the power set of the pairs of terms, one level up from the terms, exactly as the type sets are. A kind is built from the set of type sets by function sets, and a function set is a subset of the power set of a product, one level up each time. ∎

The strength that {{strength}} measured is the strength of the intersection over all type sets, and the intersections over families, over the members of a type set, over the type sets with F(C) ⊆ C and over the type sets inside a given one add nothing to it: each is an intersection over a set that the metatheory has as soon as it has the type sets. That is what {{limits}} claimed in its closing observation on cost, and this is its proof. The kinds are the exception, and the only one: each arrow in a kind is one more power set, as the remark in {{fomega}} says. That matches what {{cube}} reports, that Fω needs more than arithmetic of any finite order; the lower bound is quoted there and does not follow from the shape of this proof.
